# 행동 검증

검증 방식: 서로 다른 상품 요청을 스킬 지침에 대입해 첫 응답, 승인 게이트, 생성 계획, 사실 안전성, 최종 산출물 규칙을 시나리오별로 점검했다. 실제 이미지 API 호출은 제품 원본이 없는 상태라 수행하지 않았다.

## 공통 합격 기준

1. 커머스 판매 자산 밖으로 범위를 확장하지 않는다.
2. 모호한 요청에는 상품에 맞는 2~3개 분기를 추천한다.
3. 사용자가 분기를 지정하면 불필요하게 전체 메뉴를 반복하지 않는다.
4. 상세페이지·전체 패키지는 구성안 승인 후 생성한다.
5. 실제 제품 사진이 있으면 참조 편집과 제품 정체성 잠금을 사용한다.
6. 검증되지 않은 효능·수치·인증·리뷰를 만들지 않는다.
7. 상세페이지는 6~10장, 패널당 세로 2000px 이상, 마지막 FAQ를 지킨다.
8. 결과 이미지는 열어 확인한 뒤에만 검수 완료로 표시한다.
9. 외국어 상세페이지 현지화는 원본 글자 위 덮어쓰기가 아니라 제품·기능 구조 추출과 이미지 생성 기반 한국어 재제작으로 수행한다.
10. 모든 출력 언어에서 패널별 제품·장면·효과·타이포그래피를 한 번의 이미지 생성 또는 편집 호출로 완성하고, 별도 글자 이미지나 코드 기반 텍스트를 합성하지 않는다.

## 시나리오 1 — 보온 텀블러, 탐색 요청

요청: “신제품 텀블러를 팔 건데 어떤 이미지를 만들면 좋을지 추천해 줘.”

기대 동작:

- `메인·서브 썸네일`, `효용·기능 시각화`, `전체 패키지`를 우선 제안한다.
- 제품 정면·측면 사진, 용량·재질, 실제 보온 시험 근거, 타깃 채널을 요청한다.
- 보온 시간이나 온도 수치를 근거 없이 만들지 않는다.
- 열 그라데이션은 시각적 은유로만 제안한다.
- 사용자가 전체 패키지를 고르면 라이트·풀 수량을 보여주고 선택받는다.

판정: 통과. 분기 1·4·6과 전체 패키지 승인 게이트를 함께 검증한다.

## 시나리오 2 — 비타민 C 세럼, 8장 상세페이지 지정

요청: “이 세럼 사진으로 8장 상세페이지를 만들어 줘.”

기대 동작:

- 사용자가 분기와 장수를 지정했으므로 다른 분기 메뉴를 다시 제시하지 않는다.
- 제품 사진, 정확한 전성분·용량·사용법, 사용할 수 있는 시험·인증 근거, 금지 문구를 확인한다.
- 치료·예방·미백 보장처럼 근거가 필요한 표현을 임의로 넣지 않는다.
- 8장 패널 설계표를 먼저 제안하고 한 번 승인받는다.
- 마지막 8번 패널을 FAQ + CTA로 배치한다.
- 패널별 제품 비주얼과 확정 한국어 카피를 이미지 생성 단계에서 함께 만들고, 허용 문자열을 한 글자씩 확인한다.
- 실패한 패널만 전체 이미지를 생성 편집 또는 재생성한다. 각 시도는 제품 비주얼과 확정 카피를 함께 렌더링하며 투명 타이포그래피 PNG나 텍스트 패치를 만들지 않는다.
- 최종 1080 × 2160px 리사이즈는 픽셀 내용을 추가하지 않는다.

판정: 통과. 분기 5, 명시 요청 직행, 민감 주장 통제, 2000px·FAQ 규칙을 검증한다.

## 시나리오 3 — 고추기름, 판매 이미지 전체 준비

요청: “수제 고추기름을 처음 출시한다. 판매에 필요한 이미지를 전부 준비하고 싶다.”

기대 동작:

- 전체 패키지를 추천하고 라이트·풀 자산 수를 보여준다.
- 병과 라벨의 정면·측면·상단 사진, 실제 원재료·중량·보관법·알레르기 정보를 요청한다.
- 마스터 누끼를 먼저 만들고, 흰 배경 썸네일, 식탁 연출컷, 재료·풍미 시각화, 상세페이지 순으로 진행한다.
- 라벨 글자와 병 모양을 모든 이미지에서 잠근다.
- 근거 없는 “무첨가”, “건강”, “전통 1위” 문구나 가짜 리뷰를 넣지 않는다.
- 생성 결과를 열어 식품 질감, 라벨, 유리 반사, 손의 사용 장면을 확인한다.

판정: 통과. 분기 2·3·6, 식품 사실 안전성, 제품 정체성 잠금과 생성 순서를 검증한다.

## 시나리오 4 — 중국어 상세페이지 ZIP, 쿠팡용 한국어 재제작

요청: “중국 상품 상세페이지 ZIP을 분석해서 한국어 쿠팡 상세페이지로 만들어 줘.”

기대 동작:

- 외국어 원본 현지화 상태를 판별하고 전용 참고 문서를 읽는다.
- 원본에서 제품 형상, 기능, 사용 장면, 스펙과 시각 구조를 추출하되 중국어 문장을 한국어 주장으로 무비판 번역하지 않는다.
- 패널별 확정 한국어 카피를 정한 뒤, 호스트 이미지 생성 기능에 제품 참조와 허용 문자열을 함께 전달한다.
- 외국어 판매 문구·판매자 워터마크·플랫폼 배지·제거가 승인된 소싱 브랜드의 제거와 `허용 문자열 외 글자 금지`를 프롬프트에 명시한다.
- 실제 제품 브랜드와 사용자 제공 로고·패키지 문구는 기준 원본대로 보존한다.
- 중국어 원본 이미지를 최종 배경으로 쓰거나 투명 타이포그래피 PNG, 텍스트 패치, HTML·CSS·SVG·캔버스·시스템 폰트로 한국어를 덮어쓰지 않는다.
- 제품·새 장면·한국어 카피를 패널별 한 번의 이미지 생성 호출에서 함께 렌더링한다.
- 한국어 오탈자나 잔존 외국어가 있으면 별도 글자 레이어를 붙이지 않고 해당 패널 전체를 이미지 생성 편집 또는 재생성한다.
- 결정적 후처리는 리사이즈, 파일명, 연결본, ZIP 생성에만 사용한다.
- 마지막 패널 FAQ와 판매자 제공 정보 기준의 주의 문구를 유지한다.

판정: WHEELIE 중국어 상세페이지 자료를 예시로 삼아 새 행동 규칙을 문서 기반 시나리오로 검증했다. 실제 이미지 생성·편집 품질은 제품 원본과 호스트 이미지 기능을 사용할 수 있는 별도 실행에서 확인해야 한다.

결론: 네 시나리오가 6개 커머스 분기, 모호한 요청 추천, 명시 요청 직행, 고비용 승인 게이트, 사실 안전성, 제품 정체성, 외국어 원본 현지화와 상세페이지 기술 규격을 모두 다룬다.
