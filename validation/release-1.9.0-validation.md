# 1.9.0 검증 기록

검증일: 2026-09-19. 대상은 `plugins/machinebot-ecommerce-studio/`의 소구·시각화 기획 및 검수 지침 변경이다. 검증 종류를 구분하고, 형식 검사나 기획 실행을 신규 이미지 품질·매출 효과 검증으로 표시하지 않는다.

## 독립 기획 실행

[독립 실행 원문](forward-test-1.9.0.md). 부모 대화·과거 생성 결과·원하는 정답을 전달하지 않은 별도 에이전트가 수정된 실행 스킬과 원본 입력으로 기획했다. 외부 조회·이미지 생성은 테스트 범위에서 제외했다. 테스트 시작 당시 manifest는 아직 1.8.0이었지만 소구·장면 실행 지침은 이번 수정본이었다. 최종 1.9.0 패키지의 형식·파일 검사는 아래 별도 기록을 따른다.

| 사례 | 실제 결과 | 평가 |
|---|---|---|
| A: 원본 제품 사진 두 장만 제공 | 사진을 직접 열어 관찰 근거를 분리하고 주·보조 소구와 새 행동/구도를 기획. 제품 종류·전체 구조·관리 정보가 필요한 후반 3개 패널은 조건부로 유지 | 자료 부족을 사실 발명이나 문의 안내 패널로 채우지 않음. 생성 준비가 끝난 6장이라고 주장하지 않음 |
| B: 가상 파우치 스펙과 참조 범위 제공 | 구분 수납·손잡이 이동·겉감 생활방수·관리로 소구를 나누고 준비→이동→내부 구조→기능 표현→관리→FAQ를 연결 | 별도 분기를 요구하지 않고 6장 안에서 새 연출·장점 시각화를 기획. 생활방수 범위 확대와 추가 스펙 발명 없음 |

첫 실행 검토에서 일부 고객 가치가 기능 설명·조건 안내에 머무는 경향을 발견했다. `고객 가치`를 직접적인 사용상 이점으로 쓰도록 소구 전략과 품질 게이트를 추가 보강했다. 확인된 구조에서 설명 가능한 이점과 시험 근거가 필요한 수치·보장을 구분했다. 독립 실행 원문의 후속 절은 이 보강을 알리고 수행한 표적 재평가이며 새로운 블라인드 테스트가 아니다.
후속 결과에서 분리 포켓은 ‘소지품마다 둘 자리를 정해 보관’, 손잡이는 ‘담아 둔 물건을 함께 이동’으로 바뀌었고, 기존 내부 구조·이동 장면과 연결됐다. 이 카피는 기획 결과로 확인했으며 실제 생성 이미지의 전달력은 평가하지 않았다.

## 기존 실제 산출물의 회귀 평가

입력: 이 작업의 2026-09-18 타월 상세페이지 6장과 `output/tekla-detail-20260918/preview.jpg`. 로컬 작업 산출물이며 배포 플러그인에는 포함하지 않는다. 2026-09-19에 연락시트를 직접 열어 새 기준으로 재평가했다.

| 평가 대상 | 실제 관찰 | 1.9.0 판정 |
|---|---|---|
| 01·02 | 같은 해변 모델 포즈와 제품 배치, 휴식 메시지 반복 | 세트의 장면 다양성·정보 진전 실패 |
| 03 | 표면 고리 형태와 직조 테두리를 확대해 보여줌 | 디테일 설명 역할은 인정. 이것만으로 소재·촉감·성능은 검증 불가 |
| 04 | 해변 포즈와 얼굴 옆 로고 접사 재등장 | 새 사용 맥락 없이 앞 패널 반복 |
| 05 | 소재·크기·관리 정보를 판매자에게 확인하라는 안내 | 구매 장벽을 해소하지 못한 미완성 정보 패널 |
| 06 | 앞 해변 장면 반복, 소재·크기 답변은 확인 불가 | 장면 반복·FAQ 정보 부족 |

세트 판정: 판매 목적의 완성본으로 불합격. 기존 결과를 덮어쓰거나 재생성한 것은 아니다. 이 회귀 평가는 새 지침이 과거 실패를 식별하는지 확인하며, 새 생성 결과의 품질을 보장하지 않는다.
