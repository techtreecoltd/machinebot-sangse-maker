`validate_context.py output/harness-demo-20260921/product-context.json`: PASS. 가상 제품 테스트 설정과 직접 검수 파일을 연결했다. 개발 테스트 실행 위임을 실제 고객의 상세 카피 승인으로 재사용하지 않는다.

## 실제 제작

로컬 output/harness-demo-20260921/detail-01~06.png. 6장의 생성 원본은 모두 887×1774이며 generated-originals/에 보존했다. 최종은 비율을 유지해 1080×2160으로 리사이즈했다. 카피/제품/배경/효과는 각각 호스트 이미지 생성 호출에서 함께 렌더링했다. 별도 텍스트 패치나 합성은 없다.

정확 문구와 역할은 demo-plan.md, 호출 인자·결과 경로는 detail-generation-calls.json, 최종/원본 해시는 product-context.json에 보관한다. 외부 브랜드·상품 정보는 사용하지 않았다.

| 패널 | 직접 확인 |
|---|---|
| 01 | 제품 히어로·정리 소구·시안 표기 |
| 02 | 클립 꺼내기와 한국어 카피. 최초 영문 작업명 잔존을 발견하고 전체 패널 편집 1회로 제거 |
| 03 | 상부 구조·긴 칸 하나/앞 칸 둘·칸별 배치 |
| 04 | 이어진 칸막이와 열린 내부 디테일 |
| 05 | 트레이 단품/소품 제외의 가상 테스트 설정 |
| 06 | 사실에 답하는 FAQ 3개·CTA·시안 표시 |

최초 6회 + 02번 수정 1회 = 호스트 호출 7회. 최종 각 파일을 기준으로 검수한다. 8/10장과 외국어 ZIP 전체 재제작은 이번 6장 실행과 구분해 대화 회귀로 검사하며, 실제 8/10장·중국어 전체 제작까지 완료했다고 주장하지 않는다.
