# S9 / 1.17.1 검증

사용자가 말한 누끼컷은 흰 배경의 전문 스튜디오 제품 사진이다. 기본 제작은 중성 화이트밸런스·확산광·접지 그림자·제품 전체 여백을 갖춘 여러 각도이며, 투명 추출은 별도 명시 요청이다. 단독 요청에서 수량이 없고 자료가 충분하면 3장을 제안하며, 한 장 지정과 선택한 라이트/풀 수량을 존중한다.

## 구현

- 독립 제품컷 스킬, 표시 설명·기본 프롬프트, 공통 분기·제작·검수, intake, 두 README, PRD·목표와 배포 가이드를 일치시켰다.
- studio-product-shots.md를 독립 스킬이 읽는다. 제품 정체성·보이지 않는 면·배경·조명·명암·그림자와 세트별 각도 차이를 검사한다.
- validate_studio_shots.py는 크기·불투명도·네 모서리의 흰색 계열 여부만 검사한다. 전문 촬영 품질이나 정체성을 자동 승인하지 않는다.
- 내부 kind=cutout은 기존 제품 기록·후속 제작과 호환되도록 유지한다.

## 실제 이미지

로컬 폴더: output/harness-demo-20260921/studio-cutout-v2/

| 최종 파일 | 직접 열람한 정보 |
|---|---|
| final/studio-01-three-quarter.png | 사선에서 제품 깊이·외벽과 내부 세 칸 |
| final/studio-02-front.png | 정면 중심 구도에서 앞벽·좌우 칸 |
| final/studio-03-top-down.png | 수직 탑뷰에서 T자 칸막이·전체 내부 배치 |

호스트 이미지 편집 총 5회 중 최종 3장을 선별했다. 앞선 좌측/상부 3/4 시도는 보이는 구조가 첫 사선과 겹쳐 제외했다. 실패 파일과 초기 감사는 보존하며 서로 다른 각도 수에 넣지 않는다. 모두 1254 × 1254 RGB, 불투명 흰 배경·부드러운 접지 그림자·세 칸 구조를 직접 확인했다.

studio-shot-record.json에 최종 해시와 제외 이유가 있고, product-context.json에 원본 해시·옵션·직접 검수 연결을 저장했다. 최초 사진 자체가 합성 fixture이므로 실물 색상·재질·치수·성능을 증명하지 않는다.
