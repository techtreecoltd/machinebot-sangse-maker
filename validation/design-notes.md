# 설계 근거

## 현재 GPT v1.4에서 유지한 것

- 제품 사진과 정보를 먼저 확인한다.
- 메인·서브 썸네일, 누끼, 연출·실사용컷, 상세페이지를 지원한다.
- 보이지 않는 효용을 제품 원형을 해치지 않는 시각 효과로 제안한다.
- 기본 상품컷은 흰색 스튜디오 베이스와 중성 색감을 사용한다.
- 상세페이지는 6~10장, 패널당 세로 2000px 이상, 마지막 FAQ를 기본으로 한다.

## GPT Image 2 계열에서 커머스에만 적용한 것

- 요청을 생성·참조 편집·부분 수정으로 분류하는 사고방식
- 모호한 요청에 1~3개 방향을 이유와 함께 제안하는 방식
- 캔버스와 레이아웃을 제품 묘사보다 먼저 고정하는 프롬프트 구조
- 제품·재질·조명·팔레트·텍스트·금지 요소를 분리하는 프롬프트 블록
- 여러 참조 이미지의 역할을 제품·스타일·브랜드로 명시하는 방식
- 반복 패널에서 제품 정체성과 시각 시스템을 잠그는 규칙
- 생성 후 결과를 직접 확인하고 실패 자산만 수정하는 검수 루프

## 의도적으로 제외한 것

- 포스터, 캐릭터, 애니메이션, 게임, UI, 순수 일러스트 등 범용 이미지 분기
- 수백 개 스타일을 탐색하는 범용 스타일 라이브러리
- 로컬 CLI, API 키, 별도 이미지 생성 스크립트 의존성
- 커머스 판매 자산과 무관한 예제·갤러리·템플릿

이미지 실행은 ChatGPT Work 또는 Codex가 제공하는 호스트 이미지 생성 기능을 사용한다.

## README 표현 구조 참고

- [Gajae Code](https://github.com/Yeachan-Heo/gajae-code): 한 문장 정체성, 문제·해법 비교, 빠른 시작, 워크플로와 문서 지도를 앞쪽에 배치하는 구조를 참고했다.
- [insane-search](https://github.com/fivetaku/insane-search): 바로 시도할 프롬프트, 지원 범위, 사용 전·후 차이, 명확한 경계를 짧은 섹션으로 설명하는 구조를 참고했다.

브랜드 문구와 기능 설명은 이 프로젝트의 여섯 개 이커머스 제작 분기에 맞게 새로 작성했으며, 두 저장소의 문장이나 시각 자산을 복제하지 않았다.

## 브랜드 이미지 시스템

- `machinebot-avatar-original.png`는 현재 김머신 GPT 편집기에서 추출한 512 × 512 PNG이며 캐릭터 정체성의 기준 원본이다.
- 가로 키비주얼은 원본을 참조한 호스트 이미지 생성으로 만들되 얼굴, 머리, 안경, 은색 안드로이드 구조, 청색 눈과 회로를 잠근다.
- 타이틀 워드마크는 `MACHINEBOT`과 `ECOMMERCE VISUAL STUDIO` 두 줄로 제한한다. 여섯 개 제작 분기는 README 본문에서 설명하고 타이틀 이미지에 반복 나열하지 않는다.
- 워드마크는 호스트 이미지 생성기로 투명 PNG 글자를 직접 만든다. 코드 폰트나 HTML로 글자를 렌더링하지 않는다.
- 이미지 생성본의 작은 노이즈 픽셀은 글자 형태를 다시 그리지 않는 범위에서 제거하고, 아이보리·시안 두 색의 평면 픽셀 형태로 정리한다.
- 생성 타이포그래피는 이미지 생성 베이스 위에 이미지 대 이미지로 합성하고, 문구와 실제 알파 투명도를 직접 확인한다.
- 최종 타이틀은 단일 PNG로 평탄화하며 README에서 HTML 제목이나 HTML 정렬 레이어를 추가하지 않는다.
- 배포본에는 정체성 기준 원본, 최종 README 타이틀, 최종 YouTube 커버, 재사용 가능한 투명 서비스 워드락업만 포함한다.
