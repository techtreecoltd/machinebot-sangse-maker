# 새 세션의 첫 안내와 제작 진입

사용법 안내, 자료만 받은 첫 요청, 명시적 제작 요청에서 읽는다. 독립 스킬과 상위 오케스트레이터 모두 같은 기준을 적용한다. 이 문서를 설문처럼 전부 묻지 않는다.

## 안내와 실행

- “어떻게 써?”에는 가능한 결과와 짧은 요청 예시를 설명한다. 제작 요청이 아니므로 생성하지 않는다.
- “이걸로 메인 썸네일 만들어줘”는 해당 자산의 제작 승인이다. 전체 메뉴나 상세페이지 승인을 다시 요구하지 않는다.
- “Q&A 이미지 한 장”, “마지막 FAQ만 고쳐줘”는 [독립 상세페이지](../../machinebot-detail-page/SKILL.md)의 부분 제작으로 직행한다. [구매 결정형 FAQ](purchase-decision-faq.md)를 적용하며 전체 6·8·10장으로 확장하지 않는다.
- 결과물 종류가 불명확하면 목적·자료에서 필요한 것만 묻고 적합한 후보를 제안한다. 정해진 종류·수량·채널·문구는 재질문하지 않는다.
- “흰 배경”, “모델 사진 활용”, “문구를 크게”, “원본 구도 유지”는 표현 지시이며 일반 기본값보다 우선한다. 부분 수정은 요청한 요소만 바꾼다.

## 납품 종류와 표현을 따로 판단한다

| 납품 종류 | 선택하거나 조합할 표현 | 유지할 경계 |
|---|---|---|
| 메인·서브 썸네일 | 모델·사용, 장점 시각화·접사, 스튜디오, 정보성·후킹 카피, 조합 | 메인은 노출 위치이며 흰 배경 스타일 이름이 아니다. 한 장 요청은 한 장이다. |
| 누끼·스튜디오컷 | 확인 가능한 각도, 흰 배경, 조명·접지 그림자 | 명시한 상품컷에 모델·카피를 임의 추가하지 않는다. 투명 배경은 별도 명시 요청이다. |
| 연출·실사용컷 | 모델·손·공간·행동, 필요한 디테일·CG·문구 | 제품과 사용법을 읽을 수 있어야 한다. |
| 효용·기능 시각화 | 사용 행동, 접사, 구조·과정·개념 CG와 설명 | 보이는 외형과 검증된 기능의 주장 범위를 구분한다. |
| 상세페이지 | 제품 중심·모델·장점·정보·제품 없는 문제/맥락 컷 | 담당 기획자의 승인 구성과 수량을 따른다. 표현마다 별도 분기를 선택하게 하지 않는다. |
| 전체 패키지 | 승인 범위의 각 자산에 맞는 위 표현 | 자산별 실행자는 하나. 중복 생성·미요청 자산 추가 금지. |

표현들을 수량 체크리스트로 모두 생성하지 않는다. 한 장 안에서 모델+장점+카피를 조합할 수 있다. 배경색·텍스트·모델 유무는 납품 종류에서 자동 결정하지 않는다.

## 자료를 먼저 읽고 판단한다

1. 제공 자료를 모두 확인해 파일별 역할을 정한다: 제품 정체성, 모델/사용 맥락, 디테일/주장 근거, 디자인 참고, 기존 승인본. 못 연 자료는 미열람으로 기록한다. 실제 생성에 사용·제외한 자료와 이유를 남긴다. 모든 파일을 무조건 생성기에 넣지는 않는다.
2. 색상·구성·모델이 다른 사진을 같은 옵션으로 합치지 않는다. 조명 차이인지 다른 옵션인지 불명확하고 결과를 바꾸는 경우에만 짧게 묻는다.
3. 구매 질문·주 소구를 근거와 연결한다. 사용자 카피는 supplied 정보로 읽되 사진만으로 소재 조성·실측·효능이 검증됐다고 승격하지 않는다.
4. 썸네일은 [표현 선택](../../machinebot-thumbnail/references/thumbnail-design.md)을 메인 한 장에도 적용한다. 다른 신규 판매 이미지는 [소구 설계](sales-visual-strategy.md)를 적용한다. 단순 누끼·부분 수정에는 무관한 고객 분석을 강요하지 않는다.
5. 채널 이름을 흰 배경·무문자 의무로 추정하지 않는다. 규칙이 표현을 제한하거나 준수를 주장하려면 해당 채널·카테고리·이미지 위치의 최신 공식 안내 또는 제공 요구사항을 확인한다. 못 확인하면 미확인으로 기록하고 가능한 제작을 진행하되 등록 보장을 하지 않는다. 확인된 제한은 지키고 충돌하는 요청만 조정한다.
6. 단일 자산은 구도·핵심 메시지·사용 자료를 한두 문장으로 알리고 실행한다. 상세페이지/전체 패키지만 구성 승인을 받으며 기존 승인은 재사용한다.

## 사용법 안내 예시

> 제품 사진과 원하는 결과를 알려주세요. 썸네일은 모델 사용컷, 장점이 보이는 컷, 스튜디오 상품컷, 큰 문구가 있는 정보성 컷 등을 제품과 채널에 맞게 고르거나 조합합니다. “이 사진으로 메인 썸네일 한 장 만들어줘”처럼 요청하면 자료를 보고 방향을 정해 제작합니다. 상세페이지와 전체 패키지는 구성안을 먼저 보여드립니다.

제작 요청을 이미 받았다면 소개를 반복하지 않는다. 예시는 고정 템플릿이 아니다.

## 생성과 전달

제품·모델·장면·효과·최종 문구를 자산별 한 번의 호스트 이미지 생성/편집 호출로 만든다. 사진 위에 문구가 겹쳐 보이는 디자인은 가능하다. 별도 투명 글자 PNG나 코드로 사후 합성하는 경로는 사용하지 않는다.

실제 결과를 열어 원본 보존, 구매 질문 전달, 작은 화면의 제품 식별·카피 가독성을 확인한다. 파일·크기 통과만으로 판매력이나 전환율 향상을 검증했다고 하지 않는다.

가능한 호스트에서는 완성 이미지를 대화에 직접 표시하고 저장 경로/다운로드도 제공한다. 도구 결과에 이미 표시됐다면 중복 첨부는 필요 없다. 미리보기 불가면 그 사실과 파일 위치를 알린다. “바로 보여줘”에는 기존 결과를 다시 표시하며 재생성하지 않는다.
