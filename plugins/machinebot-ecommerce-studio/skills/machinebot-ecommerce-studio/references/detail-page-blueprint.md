# 한국형 상세페이지 설계

상세페이지는 긴 한 장을 즉흥적으로 생성하는 작업이 아니라, 각기 역할이 있는 세로 패널의 연속이다. 제품 정보량과 구매 장벽에 따라 6·8·10장 중 하나를 선택한다.
패널 배치 전에 [소구 설계와 장점 시각화](sales-visual-strategy.md)의 소구 맵과 장면 설계표를 완성한다. 아래 구조는 역할의 기본값이다. 제공된 근거와 고객의 구매 질문에 맞춰 중간 패널의 순서·역할을 조정하고, 장수와 마지막 FAQ는 유지한다.

## 공통 설계 규칙

- 패널당 기본 1080 × 2160px, 최소 세로 2000px로 제작한다.
- 각 패널은 한 가지 구매 질문에 답한다.
- 각 장에 소구 ID, 근거, 장점을 보여주는 행동·상태, 앞 장과 달라지는 구매 정보를 연결한다. 제목만 다른 동일 메시지 패널은 합치거나 다시 설계한다.
- 상세페이지 자체에 필요한 신규 연출·사용 장면·효용 시각화를 포함한다. 원본 사진 두 장의 크롭과 재배치만으로 전체 구성을 채우지 않는다.
- 헤드라인은 짧고 멀리서 읽히게 하며, 본문은 이미지 안에서 읽을 수 있는 크기로 제한한다.
- 제품명, 수치, 옵션, CTA처럼 정확해야 하는 문자열은 확정 카피 목록에 따로 기록한다.
- 마지막 패널에는 근거 있는 FAQ를 포함한다.
- 인증, 시험 결과, 수상, 리뷰, 순위, 비교표는 사용자가 근거를 준 경우에만 넣는다.
- 문제를 과장해 불안을 조장하거나 제품이 치료·예방·보장한다고 암시하지 않는다.

## 6장 구조 — 단순하고 직관적인 제품

1. `히어로`: 주 소구 한 문장과 그 가치를 보여주는 제품 장면
2. `문제·상황`: 고객이 이 제품을 필요로 하거나 갖고 싶어지는 구체적 순간
3. `핵심 해결`: 확인된 특징이 사용을 어떻게 바꾸는지 행동·과정으로 시각화
4. `주요 장점`: 근거 있는 보조 소구와 해당 부위·상태의 시각적 설명
5. `사용·구성·스펙`: 구매 장벽을 해소하는 사용 방식·구성·확정 정보
6. `FAQ + CTA`: 자주 묻는 질문 3~5개와 마무리

## 8장 구조 — 기본 권장

1. `히어로`: 제품 실루엣, 제품명, 핵심 가치
2. `고객 인사이트`: 구매 전 불편 또는 욕구
3. `제품 해답`: 차별점과 대표 사용 장면
4. `핵심 효용`: 가장 중요한 장점을 행동·구조·확인된 기능의 개념 표현으로 시각화
5. `사용 장면`: 앞 장과 다른 구매 정보를 주는 고객·공간·행동 속 제품
6. `근거·재질·스펙`: 제공된 사실에 기반한 설명
7. `사용법·구성·관리`: 단계, 구성품, 주의사항
8. `FAQ + CTA`: 자주 묻는 질문과 최종 선택 이유

## 10장 구조 — 고관여·복합 제품

8장 구조를 기반으로 다음 두 패널을 필요한 위치에 추가한다.

- `기술·구조`: 재료 레이어, 부품, 설계 원리
- `옵션·크기·비교`: SKU, 사이즈, 호환성, 실제 근거가 있는 비교

FAQ는 항상 마지막 패널로 유지한다.

## 패널 설계표

이미지 생성 전에 다음 형식으로 사용자에게 제안한다.

| 번호·소구 ID | 구매 질문·고객 가치 | 헤드라인 초안 | 시각화·장면 ID | 근거·제품 참조 | 추가되는 구매 정보 |
|---|---|---|---|---|---|
| 01·S1 | 왜 이 상황에 필요한가? | 근거 있는 가치 문장 | V1: 실제 사용하는 행동 | 확인된 기능과 제품 사진 | 대표 사용 상황 |

사용자가 수정할 수 있게 전체 문장을 길게 쓰지 말고, 패널당 핵심만 보여준다. 승인 후 확정 카피와 이미지 프롬프트를 분리해 제작한다.

## 근거가 부족한 패널

- 소재·성능·치수를 모르면 해당 주장을 보류하고 필요한 자료를 확보한다. 알 수 없는 기능을 감성 카피나 효과로 우회하지 않는다.
- 단순한 제품에 근거 없는 기능을 끼워 넣지 않는다. 확인 가능한 외형의 활용, 선택 기준, 사용 순서 등 실제로 유효한 구매 정보로 재구성한다.
- 5번 스펙 패널을 반드시 표로 채울 필요는 없다. 제공된 사용·구성 정보로 바꿀 수 있지만, 누락된 판매 필수 정보는 별도 확인 목록과 시안 상태에 남긴다.
- FAQ는 실제로 답할 수 있는 구매 질문으로 구성한다. `소재는 모릅니다`, `판매자에게 문의하세요`를 반복해 마지막 장을 채우지 않는다. FAQ와 판매에 필요한 답변이 부족하면 완성본으로 포장하지 않는다.
- 사실을 만들어 장수를 맞추거나 유효한 정보 없이 패널을 복제하지 않는다. 요청 장수로 구성이 성립하지 않으면 부족한 자료를 요청하고 근거 있는 부분만 계속 설계한다.

## 한국어 카피 규칙

- 사용자 제공 고유명사, 모델명, 옵션명은 원문을 보존한다.
- 수치와 단위 사이 표기를 일관되게 한다.
- 기능 설명을 고객 효용으로 번역하되 검증되지 않은 결과를 더하지 않는다.
- “무조건”, “완벽”, “100%”, “최고”, “1위”, “치료”, “예방” 같은 절대 표현은 근거와 사용 허용이 확인되지 않으면 쓰지 않는다.
- FAQ 답변에서 모르는 내용은 내부 확인 목록에 남기고, 고객에게 제공할 정확한 답변을 확보한 뒤 반영한다.
