# CG 시각화 판단 카탈로그

연출컷·효용 시각화·썸네일 세트·상세페이지를 기획할 때 제품 사진만으로 구매 가치가 보이는지 먼저 판단한다. 보이지 않는 작동, 표면, 접촉 부위, 흐름, 차단, 구조를 CG로 설명하면 이해가 빨라지는 경우가 있다. 이 카탈로그는 CG를 장식으로 붙이는 규칙이 아니라, 필요한 개념을 발견하고 사실 경계를 지키는 판단 기준이다.

## 판단 순서

1. `특징 → 고객이 얻는 변화 → 구매 질문 → 관찰 가능한 장면`을 만든다.
2. 일반 사진만으로 그 변화가 보이는지 묻는다. 보이지 않는 경로·차단·분포·접촉 부위·재질감·구조가 핵심이면 CG 후보로 올린다.
3. 같은 모델·옵션에 대한 근거를 `observed`, `supplied`, `documented`, `synthetic-spec` 중 하나로 고정한다.
4. 근거가 기능·성능을 지지하면 CG로 개념을 설명하고, 근거가 외형·행동에 그치면 보이는 범위의 오버레이만 사용한다. 미확인 효과는 사진과 CG 모두에서 보류한다.
5. 한 컷이 새 구매 정보를 추가하는지 확인한다. 단순 광택, 빛줄기, 그라데이션, 빨간색 강조만으로 소구를 만들지 않는다.
6. 확정된 제품·장면·CG·카피를 하나의 호스트 이미지 생성 또는 편집 호출에서 평탄화한다. 투명 CG 레이어, HTML·CSS·SVG·캔버스 합성, 사후 텍스트 패치는 만들지 않는다.

## 유형별 선택표

| 개념 | CG가 필요한 신호 | 근거가 있을 때 | 근거가 외형·행동에 그칠 때 | 금지하는 확장 |
|---|---|---|---|---|
| 차단·보호·흐름 | 자외선·빛·열·공기·수분이 표면에서 어떻게 멈추거나 이동하는지가 구매 질문 | 시험·공식 자료의 대상·조건에 맞춰 개념 광선·흐름을 표시하고 수치가 있으면 그대로만 표기 | 실제 사용 장면과 표면·구조를 보여주며 차단 효과를 표현하지 않음 | 숫자 없는 차단 보장, 전후 개선, 시험처럼 보이는 과장 |
| 재질·표면 | 표면의 짜임·거칠기·광택·두께감이 선택에 직접 영향 | 같은 옵션의 소재 문서와 접사로 질감·구조를 확대 | 사진에서 보이는 표면 인상만 `표면 질감 연출`로 표시 | 혼용률·흡수·통기·내구·촉감 단정 |
| 사용·신체 접촉 | 제품이 어느 부위에 닿고 어떤 동작으로 쓰이는지가 핵심 | 실제 사용법·치수·착용 자료에 맞춰 모델 동작, 접촉면, 자세를 명확히 표현 | 확인된 손·신체 접촉과 공간 관계만 보여주고 착용감·교정 효과는 말하지 않음 | 가짜 사용법, 맞춤성·편안함·안전 보장 |
| 부위·해부학적 관심 | 제품 가치가 특정 신체 영역이나 압력·정렬 부위의 위치를 알아야 이해됨 | 같은 모델의 설명 자료 범위에서 단순 실루엣·접촉 영역·관심 부위 색상 강조 | 사용자가 지정한 부위를 `관심 부위`로만 표시하고 건강 효능 문구를 보류 | 통증 치료·완화, 질환 예방·교정, 의학적 전후 결과 |
| 구조·메커니즘 | 내부 칸·레이어·접점·조립·작동 순서가 외부 사진에 드러나지 않음 | 원본·도면·설명서로 확인한 구조만 인셋·단면·화살표로 설명 | 열린 상태·손 동작·접사로 확인 가능한 구조만 보여줌 | 숨은 부품·단면·강도·성능 발명 |

## 대표 판단 예시

### 자외선 차단

공식 시험이나 동일 옵션의 문서에 차단 기능과 조건이 있으면 햇빛 방향과 표면에서 멈추는 광선을 단순한 개념 CG로 표현할 수 있다. 수치·시험 조건이 없으면 광선이 막히는 결과를 만들지 않고, 야외 사용 맥락과 제품이 햇빛 아래 놓인 상태만 연출한다. `UV 차단` 문구가 없더라도 막힌 광선은 효과 주장으로 판정한다.

### 재질감

같은 제품의 소재 설명과 표면 사진이 있으면 접사와 얕은 CG 확대를 함께 써서 짜임·표면 구조를 보여준다. 사진에서 보이는 반사나 색만으로 `방수`, `흡수`, `통기`, `고급 소재`를 결론내리지 않는다. 허용 문구는 `표면 질감`, `짜임이 보이는 접사`처럼 관찰 범위에 맞춘다.

### 실제 사용과 신체 부위

모델이 제품을 쓰는 장면은 제품과 손·신체의 접점, 사용 방향, 크기 관계를 명확히 하는 데 쓴다. 척추 제품처럼 특정 부위가 구매 질문이면 단순 실루엣과 접촉 영역을 우선하고, 빨간색은 문서·사용자가 지정한 `관심 부위`를 표시하는 시각 표기로 제한한다. 의료 자료 없이 `통증 부위`, `교정`, `치료`, `완화`를 확정하지 않는다.

## 연출컷에 적용하는 체크리스트

- 이 컷에서 글자를 지워도 어떤 보이지 않는 가치가 드러나는가?
- 그 가치는 사진·설명서·시험·사용자 제공 자료 중 어디에서 확인됐는가?
- CG가 새 사실을 만들지 않고 위치·방향·범위·질감·구조를 명확히 하는가?
- 제품의 형상·옵션·로고와 모델의 접촉·자세가 원본 자료와 맞는가?
- 같은 세트의 다른 컷과 다른 구매 질문을 답하는가?
- 최종 제품·배경·CG·카피가 한 호스트 호출의 평탄화 이미지로 직접 렌더링되는가?

근거가 부족하면 CG 자체를 포기하는 것이 아니라 표현 수준을 낮춘다. 효과 대신 사용 장면, 차단 대신 위치와 구조, 통증 대신 관심 부위, 소재 성능 대신 표면 관찰로 재구성한다. 그래도 구매 가치를 설명할 수 없으면 `보류` 또는 `자료 요청`으로 기록한다.
