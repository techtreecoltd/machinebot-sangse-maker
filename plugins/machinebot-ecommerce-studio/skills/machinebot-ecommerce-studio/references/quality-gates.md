# 품질 게이트

최종 전달 전에 해당되는 항목을 확인한다. 하나라도 확인하지 못한 항목은 미검증으로 표시한다.

## 소구·시각화 — 기획과 생성 결과 모두 검수

단순 누끼·배경 제거·문자 교정 외의 판매 제작에 적용한다. 생성 전 소구 맵·장면 설계표를 확인하고, 생성 후 실제 이미지를 같은 기준으로 다시 판단한다.

- 주 소구가 특정 고객의 상황·욕구와 연결되고, 제품 특징을 고객이 얻는 가치로 설명한다.
- 고객 가치가 스펙 재서술이나 `기능·주의사항을 알 수 있음`에 머물지 않는다. 확인된 특징이 사용·정리·이동·경험에 주는 이점을 설명하되 성능 수치·보장을 덧붙이지 않는다.
- 기능적·감성적 가치를 검토했으며 미확인 기능을 억지로 추가하지 않았다. 카테고리의 일반 용도를 제품만의 우위로 주장하지 않는다.
- 소구마다 근거와 허용 주장 범위를 추적할 수 있다. 시각 효과도 같은 근거 기준을 충족한다.
- 장점 설명 패널은 사용 행동·구조·과정·상태 등으로 그 장점을 보여준다. 글자를 가렸을 때도 장점의 대상이나 필요 상황을 식별할 수 있다.
- 필요 상황 패널은 이 제품을 왜 쓰거나 원하는지 설명한다. 장소만 예쁘게 바꾼 장면으로 대체하지 않는다.
- 각 패널이 새 구매 정보 또는 구매 장벽 해소를 담당한다. 같은 의미의 감성 문장을 반복하지 않는다.
- 미확인 정보 안내로 스펙·FAQ 패널을 채우지 않는다. 부족한 필수 정보는 별도 확인 목록과 시안 상태에 명시한다.

## 장면 다양성 — 세트 단위 검수

- 전체 패널을 나란히 보고 제품 중심 컷·사용/필요 상황·장점 설명 등 계획한 역할이 실제로 구별되는지 확인했다.
- 같은 사진의 크롭·반전·문구·색감 변경, 동일 포즈의 재생성을 새 연출로 세지 않았다.
- 동일한 장면이 여러 패널의 주 이미지로 반복되지 않는다. 배경만 달라지고 새 사용 맥락이 없으면 반복으로 판정한다.
- 접사는 이전에 보이지 않은 유효한 디테일을 설명한다. 로고만 확대하며 장수를 채우지 않는다.
- 제품 정체성을 유지하면서 필요한 새 행동·구도·공간을 만들었다. 새 장면을 위해 보이지 않는 부품을 발명하지 않았다.
- 원본만 사용·동일 구도 유지 등 사용자 지정 예외는 기록하고 그 범위 안에서 평가했다.

소구의 근거 부족, 장점을 보여주지 못한 시각화, 새 정보 없는 장면 반복은 해당 패널을 수정해야 하는 실패다. 규격·오탈자 통과나 구성 승인으로 상쇄하지 않는다. 정확한 사실·카피만 확인했다고 판매력이 검증됐다고 말하지 않는다.

검수 기록 예시:

| 패널·파일 | 소구·장면 ID | 실제로 보이는 구매 정보 | 근거·시각화·중복 판정 | 조치 |
|---|---|---|---|---|
| 03 | S1·V2 | 히어로와 같은 포즈만 반복 | 근거 통과, 시각화·중복 실패 | 확인된 구조가 보이는 장면으로 재생성 |

같은 문제가 두 번 반복되면 원인과 가능한 변경 범위를 제시하고 실패 상태를 유지한다. 의도대로 보이는지에 대한 질적 검수이며 전환율·매출의 실증 검증을 뜻하지 않는다.

## 사실·카피

- 제품명, 모델명, 옵션, 용량, 단위가 사용자 자료와 일치한다.
- 효능, 인증, 수치, 수상, 리뷰, 순위, 비교 우위에 근거가 있다.
- 가짜 후기, 별점, 인증 마크, 플랫폼 배지, 언론 로고가 없다.
- 건강·식품·화장품·아동·안전 관련 문구가 치료·예방·보장으로 과장되지 않았다.
- FAQ가 제공된 정보만 사용하며 모르는 내용을 추측하지 않는다.

## 제품 정체성

- 제품 실루엣과 구성 부품이 기준 사진과 같다.
- 패키지 색상, 로고 위치, 라벨 배치가 패널 사이에서 흔들리지 않는다.
- 보이지 않는 면·내부·부속이 임의로 추가되지 않았다.
- 손과 인물의 제품 사용 방식이 실제로 가능해 보인다.

## 시각 품질

- 기본 상품컷에 누런 색감, 과한 주황 조명, 플라스틱 CGI 광택이 없다.
- 소품과 효과가 제품을 가리지 않는다.
- 한 세트의 팔레트·표현 수준이 일관되고 장면별 광원·그림자가 자연스럽다. 구도 변화로 제품 크기나 성능을 과장하지 않는다.
- 효용 시각화가 측정 결과나 실제 단면으로 오인될 표현을 쓰지 않는다.
- 잘린 제품, 중복 부품, 이상한 반사, 왜곡된 손·손가락이 없다.

## 텍스트와 레이아웃

- 각 최종 자산은 제품·장면·효과·타이포그래피가 한 번의 이미지 생성 또는 편집 호출에서 함께 렌더링된 평탄화 이미지다.
- 텍스트 없는 베이스, 투명 타이포그래피 PNG, 텍스트 패치, HTML·CSS·SVG·캔버스·시스템 폰트 합성을 사용하지 않았다.
- 모든 출력 언어 문자열이 확정 카피와 한 글자씩 일치한다.
- 자모 깨짐, 가짜 글자, 중복 문구, 잘린 텍스트가 없다.
- 헤드라인·본문·주석의 위계와 대비가 분명하다.
- 모바일 화면에서 읽을 수 있는 글자 크기와 안전 여백이 있다.
- 외국어 원본 현지화 결과에 제거 대상으로 분류한 외국어 판매 문구·판매자 워터마크·플랫폼 배지·소싱 브랜드·외계 문자가 남아 있지 않다.
- 실제 제품 브랜드와 사용자 제공 로고·패키지 문구는 기준 원본대로 보존됐다.
- 외국어 원본 위에 불투명 상자나 코드 텍스트를 덮어 잔존 문구를 숨기지 않았다.
- 이미지 생성 단계에서 허용한 한국어 문자열 외 임의 문구가 추가되지 않았다.

## 기술 규격

- 상세페이지 각 패널의 세로 크기가 2000px 이상이다.
- 썸네일은 요청 비율과 파일 형식을 따른다.
- 누끼 결과는 흰색 또는 아주 옅은 중성 스튜디오 배경, 중성 화이트밸런스, 자연스러운 접지 그림자와 전체 제품 여백을 갖춘다.
- 누끼 세트는 같은 제품의 확인 가능한 여러 각도를 제공하며, 같은 이미지를 크롭만 달리해 반복하지 않는다.
- 투명 PNG는 기본 누끼 결과로 요구하지 않는다. 사용자가 별도로 요청한 투명 추출물은 추가 편집 자산으로 구분한다.
- 파일 번호와 용도가 산출물 목록과 일치한다.
- 마지막 상세페이지 패널에 FAQ가 있다.

## 전달

- 생성된 파일을 실제로 열어 확인했다.
- 소구 ID·장면 ID·실제 결과 파일의 연결과 실패 패널 수정 내역을 남겼다.
- 미검증 주장과 사용자 확인이 필요한 항목을 별도로 적었다.
- 수정 요청 방법을 `파일 번호 + 바꿀 요소 + 유지할 요소` 형식으로 안내한다.
