# 품질 게이트

최종 전달 전에 해당되는 항목을 확인한다. 하나라도 확인하지 못한 항목은 미검증으로 표시한다.

## 사실·카피

- 제품명, 모델명, 옵션, 용량, 단위가 사용자 자료와 일치한다.
- 효능, 인증, 수치, 수상, 리뷰, 순위, 비교 우위에 근거가 있다.
- 가짜 후기, 별점, 인증 마크, 플랫폼 배지, 언론 로고가 없다.
- 건강·식품·화장품·아동·안전 관련 문구가 치료·예방·보장으로 과장되지 않았다.
- FAQ가 제공된 정보만 사용하며 모르는 내용을 추측하지 않는다.

## 제품 정체성

- 제품 실루엣과 구성 부품이 기준 사진과 같다.
- 패키지 색상, 로고 위치, 라벨 배치가 패널 사이에서 흔들리지 않는다.
- 보이지 않는 면·내부·부속이 임의로 추가되지 않았다.
- 손과 인물의 제품 사용 방식이 실제로 가능해 보인다.

## 시각 품질

- 기본 상품컷에 누런 색감, 과한 주황 조명, 플라스틱 CGI 광택이 없다.
- 소품과 효과가 제품을 가리지 않는다.
- 한 세트의 팔레트, 조명 방향, 그림자, 제품 크기 감각이 일관된다.
- 효용 시각화가 측정 결과나 실제 단면으로 오인될 표현을 쓰지 않는다.
- 잘린 제품, 중복 부품, 이상한 반사, 왜곡된 손·손가락이 없다.

## 텍스트와 레이아웃

- 모든 한국어 문자열이 확정 카피와 한 글자씩 일치한다.
- 자모 깨짐, 가짜 글자, 중복 문구, 잘린 텍스트가 없다.
- 헤드라인·본문·주석의 위계와 대비가 분명하다.
- 모바일 화면에서 읽을 수 있는 글자 크기와 안전 여백이 있다.
- 외국어 원본 현지화 결과에 제거 대상으로 분류한 외국어 판매 문구·판매자 워터마크·플랫폼 배지·소싱 브랜드·외계 문자가 남아 있지 않다.
- 실제 제품 브랜드와 사용자 제공 로고·패키지 문구는 기준 원본대로 보존됐다.
- 외국어 원본 위에 불투명 상자나 코드 텍스트를 덮어 잔존 문구를 숨기지 않았다.
- 이미지 생성 단계에서 허용한 한국어 문자열 외 임의 문구가 추가되지 않았다.

## 기술 규격

- 상세페이지 각 패널의 세로 크기가 2000px 이상이다.
- 썸네일은 요청 비율과 파일 형식을 따른다.
- 누끼 결과는 실제 투명 배경인지 확인한다.
- 파일 번호와 용도가 산출물 목록과 일치한다.
- 마지막 상세페이지 패널에 FAQ가 있다.

## 전달

- 생성된 파일을 실제로 열어 확인했다.
- 미검증 주장과 사용자 확인이 필요한 항목을 별도로 적었다.
- 수정 요청 방법을 `파일 번호 + 바꿀 요소 + 유지할 요소` 형식으로 안내한다.
