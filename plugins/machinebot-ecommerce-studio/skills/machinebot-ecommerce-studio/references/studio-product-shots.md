# 제품 스튜디오 마스터컷

이 프로젝트에서 사용자가 말하는 `누끼컷`은 투명 배경 오브젝트 추출물이 아니라, 제품을 판매 페이지의 기준 이미지로 사용할 수 있는 흰색 스튜디오 제품컷이다. 내부 자산 종류 값은 기존 연결 계약과 호환하기 위해 `cutout`을 유지하지만, 산출물의 의미와 검수는 이 문서가 정한다.

## 기본 산출물

- 라이트: 1~2장
- 풀: 2~4장
- 기본 각도: 정면, 정면 3/4, 측면 또는 반대 3/4, 상부 3/4 중 제품 형상과 자료로 확인 가능한 각도
- 각도 수는 자료에 없는 면을 상상해 채우지 않는다.
- 단독 요청에 수량이 없고 자료가 충분하면 정면·사선·탑뷰 등 3장을 기본 제안한다. 명시한 한 장 요청과 이미 선택한 라이트·풀 수량이 우선한다.

## 촬영 계약

- 제품 기준 사진의 형상, 비율, 색상, 로고, 라벨, 구성 부품을 유지한다.
- 배경은 흰색 또는 아주 옅은 중성 회색의 무한 배경으로 둔다.
- 화이트밸런스는 중성으로 맞추고 누런 색 캐스트를 제거한다.
- 큰 확산광과 부드러운 명암을 사용한다. 제품 아래에는 자연스러운 접지 그림자를 둔다.
- 제품은 프레임 중앙에 충분한 안전 여백을 두고, 각도마다 제품 전체가 잘리지 않게 한다.
- 같은 조명 방향, 그림자 농도, 제품 크기 감각을 유지한다.
- 소품, 인물, 카피, 장식 효과를 넣지 않는다. 사용 장면과 소구 설명은 연출·효용·상세 분기에서 담당한다.
- 최종 컷은 불투명한 흰색 배경을 가진 평탄화 이미지다. 투명 PNG는 이 분기의 기본 결과가 아니다.

## 생성 순서

1. 가장 정확한 제품 원본을 직접 열고 잠글 형상·색상·문구·구성 부품을 기록한다.
2. 자료에서 확인 가능한 각도만 산출물 목록에 배정한다.
3. 각도별로 제품 사진을 기준으로 편집하거나 생성하되, 배경·광원·카메라만 바꾼다.
4. 각 결과를 직접 열어 제품 정체성, 흰 배경, 조명, 그림자, 여백, 세트 일관성을 비교한다.
5. 통과한 컷만 `cutout` 자산으로 후속 분기에 인계한다.

## 실패 조건

- 투명 배경만 있고 전문적인 흰색 스튜디오 촬영 기준이 없다.
- 제품이 파란색·노란색 등 다른 색으로 변하거나 형상·칸·부품이 달라진다.
- 배경이 회색·누렇거나 그림자가 제품을 떠 보이게 한다.
- 다른 파일·생성 호출이라도 보이는 면과 구조가 같고 카메라 높이만 조금 바뀌면 새 각도로 세지 않는다. 세트 전체를 비교해 중복 컷은 제외하거나 뚜렷한 다른 구도로 수정한다.
- 제품이 잘리거나 과도한 반사·CGI 광택·가짜 로고가 생긴다.
- 자료에 없는 후면·내부·부속을 생성한다.

투명 배경 파일이 별도로 필요한 사용자가 명시하면 그것은 이 마스터컷과 구분된 추가 편집 요청으로 기록한다. 그 파일이 생성되더라도 기본 `누끼컷` 수량을 대신하지 않는다.
