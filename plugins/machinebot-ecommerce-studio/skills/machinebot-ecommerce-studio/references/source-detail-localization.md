# 외국어 상세페이지 현지화

중국어·일본어 등 외국어 상세페이지 ZIP, 스크린샷, 판매 페이지 이미지를 한국형 상세페이지로 재제작할 때 적용한다. 번역문을 원본 위에 덮는 작업이 아니라, 제품과 정보 구조를 추출해 새 한국어 커머스 이미지로 재생성하는 분기다.

## 1. 원본 분석

원본 파일을 패널 순서대로 펼치고 다음을 분리한다.

- `제품 기준`: 형상, 색상, 소재, 포켓·버튼·바퀴·손잡이 등 보존할 구조
- `브랜드 기준`: 실제 제품 제조사 브랜드, 사용자 제공 로고, 패키지 문구처럼 제품 정체성과 함께 보존할 요소
- `기능 증거`: 실제 사진으로 확인되는 사용법과 구성
- `판매자 주장`: 용량, 치수, 무게, 소재, 호환성처럼 사용자 확인이 필요한 정보
- `시각 구조`: 히어로, 사용 장면, 기능 그리드, 사양, FAQ의 설득 순서
- `폐기 요소`: 외국어 판매 문구, 판매자 워터마크, 플랫폼 배지, 사용자가 제거를 승인한 소싱 브랜드, 가짜 리뷰와 근거 없는 과장

외국어 문장을 그대로 번역해 확정 사실로 승격하지 않는다. 사진으로 확인할 수 없는 수치와 주장은 `판매자 제공 자료 기준` 또는 `아직 확실하지 않음`으로 분리한다.
실제 제품 브랜드는 기본적으로 보존한다. OEM·노브랜드 상품처럼 브랜드 교체 권한이 확인됐거나 사용자가 제거를 승인한 경우에만 제거 대상으로 분류한다.
분석 후 [소구 설계와 장점 시각화](sales-visual-strategy.md)를 적용해 고객 가치·근거·장면을 연결한다. 원본 패널 순서와 포즈를 그대로 답습하지 않고, 한국어 상세페이지의 구매 질문에 맞춰 새 사용·필요 상황과 장점 시각화를 설계한다. 외국어 원본에 있던 효과도 검증된 기능의 증거로 취급하지 않는다.

## 2. 제품 추출과 참조 준비

1. 정면·측면·후면·내부·사용 장면에서 가장 정확한 제품 이미지를 고른다.
2. 제품 형상과 기능을 한 장에서 보기 어려우면 작은 참조 시트를 만들 수 있다. 참조 시트는 이미지 생성 입력 전용이며 최종 패널로 사용하지 않는다.
3. 색상 옵션마다 마스터 제품 참조를 고정한다.
4. 원본 상세페이지 전체를 최종 배경으로 재사용하지 않는다.

## 3. 패널별 이미지 생성

패널마다 한 번의 독립 생성 또는 편집 호출로 제품·새 장면·효과·확정 한국어 카피를 함께 렌더링한다. 결과는 별도 레이어가 없는 최종 평탄화 이미지 한 장이어야 한다. 프롬프트에 다음 블록을 모두 포함한다.

1. `제품 잠금`: 참조 제품의 실루엣, 소재, 색상, 부품 위치 유지
2. `패널 목적`: 히어로, 사용 방식, 수납, 디테일, 사양, FAQ 중 하나
3. `허용 문자열`: 이미지에 들어갈 한국어와 보존할 실제 제품 브랜드명을 따옴표로 정확히 열거
4. `원문 제거`: 외국어 판매 문구, 판매자 워터마크, 플랫폼 배지, 제거가 승인된 소싱 브랜드와 기존 판촉 문구 제거
5. `문자 금지`: 허용 문자열 외 글자, 외계 문자, 임의 숫자와 가짜 로고 금지
6. `레이아웃`: 제품과 글자가 겹치지 않는 안전 여백과 모바일 가독성
7. `소구·새 장면`: 소구 ID·근거 범위·고객에게 보여줄 장점/필요 상황, 원본과 달라지는 행동·구도

프롬프트 핵심 문장 예시:

> 원본 이미지의 외국어 판매 문구, 판매자 워터마크, 플랫폼 배지와 기존 판촉 문구를 완전히 제거한다. 실제 제품 브랜드 `WHEELIE`는 제품 정체성으로 보존한다. 아래 따옴표로 지정한 한국어와 `WHEELIE` 외에는 어떤 글자도 만들지 않는다. 한국어는 현대적인 고딕체로 정확하고 또렷하게 렌더링하며 오탈자, 깨진 자모, 외계 문자를 넣지 않는다.

긴 설명을 한 패널에 몰아넣지 않는다. 한국어 정확도를 높이기 위해 헤드라인, 짧은 서브 카피, 2~6개 라벨 수준으로 분산한다.

## 4. 수정 분기

생성 결과에 한국어 오탈자, 중국어 잔존, 가짜 글자가 있으면 다음 순서로 수정한다.

1. 오류 위치와 올바른 문자열을 특정한다.
2. 제품·구도·색상을 유지하되 전체 패널을 최종 이미지로 다시 출력하는 이미지 생성 편집을 요청한다.
3. 편집이 실패하면 해당 패널 전체를 더 짧은 카피로 재생성한다.
4. 같은 문제가 두 번 반복되면 사용자에게 문구 축약, 페이지 간 정보 재배치 또는 제작 명세만 전달 중 가능한 대안을 선택받는다.

이 분기에서는 텍스트 없는 베이스, 투명 타이포그래피 PNG, 텍스트 패치, 불투명 사각형, HTML·CSS·SVG·캔버스·시스템 폰트로 원문을 가리거나 한국어를 덮어쓰지 않는다. 별도 글자 레이어 방식으로 전환하는 예외를 두지 않는다.

## 5. 허용되는 결정적 후처리

글자를 새로 그리지 않는 다음 작업만 허용한다.

- 1080 × 2160px 등 채널 규격 리사이즈
- 파일 번호와 이름 정리
- 패널 세로 연결본 생성
- PNG·JPG 인코딩과 ZIP 패키징

## 6. 검수

- 제품 형상과 옵션 색상이 패널 사이에서 일치하는가
- 확정 한국어 문자열이 한 글자씩 일치하는가
- 제거 대상으로 분류한 외국어 판매 문구·판매자 워터마크·플랫폼 배지·소싱 브랜드·외계 문자가 남지 않았는가
- 실제 제품 브랜드와 사용자 제공 로고·패키지 문구가 기준 원본대로 보존됐는가
- 원본의 미검증 주장을 새 한국어 사실처럼 단정하지 않았는가
- 마지막 패널에 제공된 정보만 사용한 FAQ가 있는가
- 각 패널을 실제로 열어 모바일 가독성과 잘림을 확인했는가
- 공통 [품질 게이트](quality-gates.md)의 소구·시각화·장면 다양성도 통과했는가
