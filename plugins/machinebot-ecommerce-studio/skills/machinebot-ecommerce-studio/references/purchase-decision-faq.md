# 구매 결정형 FAQ

상세페이지 마지막 패널, 외국어 상세 현지화, 패키지의 상세 마지막 슬롯, 지정된 FAQ 한 장의 제작·수정에서 읽는다. FAQ 한 장은 상세페이지의 부분 자산이며 새 일곱 번째 분기가 아니다. 전체 상세페이지의 6·8·10장과 구성 승인 계약은 유지한다.

## 1. 구매 직전의 질문부터 정한다

FAQ의 목적은 앞 패널을 읽고도 남은 선택 장애물을 해소하는 것이다. 앞에서 설명한 장점을 질문형으로 되풀이하거나 제품마다 크기·소재·배송을 고정 순서로 넣지 않는다.

1. 제품·옵션·대상 고객과 앞 패널의 설명을 확인한다.
2. 남은 구매 장벽을 모은다: 내 사용 조건에 맞는가, 호환되는가, 어느 옵션인가, 별도 준비물이 필요한가, 사용·관리가 번거로운가, 어떤 제한이 있는가. 배송·교환·보증은 해당 판매자의 확인된 정책이 구매 결정을 좌우할 때만 넣는다.
3. 각 질문을 `중요도 → 답할 근거 → 앞 패널 대비 새 판단 정보` 순으로 선별한다. 비슷한 질문은 합치고, 결정을 바꾸지 않는 질문은 뺀다.
4. 기본 3~5개로 구성한다. 충분한 근거와 서로 다른 구매 장벽이 있을 때만 6개까지 사용한다. 명시한 수량은 먼저 존중하되 근거가 부족하면 사실을 만들어 채우지 않는다.

“크기가 얼마인가요?”보다 “내 기기와 함께 쓸 수 있나요?”가 유용할 수 있지만, 질문만 바꿔 놓고 외형 치수만 답하면 해결되지 않는다. **질문의 범위에 답할 수 있는 근거**가 필요하다. 파우치 외형을 내부 실측·수납 시험처럼 쓰거나 화면 인치만으로 기기 호환을 보장하지 않는다.

## 2. 답변은 결론과 판단 조건을 준다

첫 문장에 가능한 범위·불가능한 조건·선택 기준을 답하고, 필요한 수치·근거·주의만 1~2문장 덧붙인다. “누구나”, “전부 호환”, “안심하세요” 같은 근거 없는 확신을 쓰지 않는다. 조건부 답변도 구매자가 무엇을 확인할지 알 수 있어야 한다.

| 근거 상태 | 처리 |
|---|---|
| 정확한 옵션의 자료로 답할 수 있음 | 결론 + 조건/제한 + 필요한 확인 행동으로 확정 |
| 일부 조건만 확인됨 | 확인된 범위로 질문을 좁히고 제한을 명시. 외형 정보만 있으면 수납 보장 대신 확인 가능한 가방 배치 기준 등으로 재구성 |
| 구매 결정에 필수인 사실이 없음 | 내부 확인 목록에 두고 해당 사실만 질문. 답을 얻기 전 그 FAQ/최종 납품은 시안 또는 보류로 표시 |
| 결정에 영향 없는 질문이거나 근거 없음 | 삭제하거나 근거 있는 다른 구매 장벽으로 교체. 소비자용 패널을 문의 안내로 채우지 않음 |

## 3. 생성 전 FAQ 브리프

기존 `product-context.json`의 `plans.scope` 또는 연결된 제작 기록에 아래 표를 둔다. 새 런타임·필수 JSON 필드·별도 상태 파일을 도입하지 않는다. 전체 상세/패키지는 이 브리프를 기존 구성 승인에 포함한다. 이미 승인한 FAQ의 표현 개선·오탈자 수정과 명시한 한 장 요청에 전체 구성 승인을 다시 요구하지 않는다.

| ID | 남은 구매 장벽·선정 이유 | 질문 | 확정 답변·조건 | 근거 ID·허용 범위 | 앞 패널 대비 새 판단 정보 |
|---|---|---|---|---|---|
| F1 | 사용 중인 기기와의 호환 | 케이스를 끼운 채 쓸 수 있나요? | 케이스 포함 두께가 14mm 이하면 사용할 수 있습니다. 결합 부위의 전체 두께를 확인해 주세요. | 가상 예시 fact-1: 거치부 허용 두께 14mm. 모든 케이스 보장은 아님 | 케이스 포함 실제 두께로 적합성 판단 |

이 행은 가상 구조 예시이며 다른 제품의 사실로 복사하지 않는다. 브리프에 스타일, 정확 문자열, 산출물 범위, 미해결 사실도 연결한다. 근거·옵션·정책이 바뀌면 영향받는 답변과 승인·검수를 다시 확인한다.

## 4. 정보 중심 디자인 기본값

기본은 Apple식 정보 디자인의 원리인 명확한 위계·정렬·절제된 색·간결한 구분이다. 특정 브랜드 로고나 화면을 복제하지 않는다. 브랜드 가이드와 사용자 지정 표현은 우선 적용하며, 히어로·연출 패널까지 같은 정보 레이아웃으로 통일하지 않는다.

- 밝은 중성 바탕, 진한 본문, 현대적인 한국어 산세리프, 얇은 구분선, 한 개의 절제된 강조색을 기본으로 한다. 글자 굵기·크기·대비로 질문과 답변을 구분한다.
- 상단 제목과 제품 식별 영역은 전체 높이의 약 15~25%, 답변 영역은 약 65~80%를 출발점으로 잡는다. 고정 합격 수치는 아니며 실제 카피와 가독성으로 조정한다. 제품컷은 작게 쓰거나 불필요하면 생략한다.
- 모바일에서는 단일 열을 우선한다. 질문 1~2줄, 답변 2~3줄을 목표로 문장을 편집한다. 긴 예외를 지우거나 글씨를 과도하게 줄여 밀도를 맞추지 않는다.
- 1080px 폭 기준 좌우 64~80px, 제목 52~68px, 질문 34~42px, 본문 30~36px 정도를 시작 지시로 사용할 수 있다. 숫자만으로 통과시키지 않고 최종 이미지를 모바일 폭에서도 확인한다.
- 거대한 제품 사진·반복 Q 원형 배지·장식적인 명조/손글씨·큰 CTA가 답변 영역을 밀어내지 않게 한다. 브랜드가 명조를 지정했다면 제목 등에 제한해 적용하되 답변 가독성을 유지한다.
- CTA는 필요한 경우 짧게 한 줄만 둔다. 긴급성·품절 임박·혜택·가격은 근거 없이 추가하지 않는다.

## 5. 이미지 호출로 연결

프롬프트에 `역할=구매 결정형 FAQ`, 구매 장벽별 확정 질문/답변, 근거상 제한, 정확한 허용 문자열, 브랜드 예외, 위계·면적·정렬·안전 여백을 포함한다. “깔끔하게” 또는 “Apple 스타일” 한마디로 대신하지 않는다. 히어로의 색·브랜드는 이어 받되 큰 사진과 헤드라인 비중까지 복제하지 않는다.

기본 1080×2160px, 최소 높이 2000px를 유지한다. 제품·배경·최종 문구를 **한 번의 호스트 생성/편집 호출**로 함께 렌더링한다. 텍스트 없는 베이스·별도 타이포 PNG·코드 글자 합성은 금지한다. 텍스트 중심 FAQ는 소구를 이미 설명한 제품 장면을 새로 반복 생성할 의무가 없다.

## 6. 결과 검수와 재시도

다음 항목을 실제 파일과 브리프를 대조해 기록한다. 하나라도 실패하면 해당 패널을 완료로 표시하지 않는다.

1. **결정 도움:** 질문마다 어떤 구매 장벽을 해소하는지 말할 수 있고 답변이 그 질문에 답한다. “상황에 따라 다릅니다”와 사양 재나열만으로 끝나지 않는다.
2. **근거:** 조건·치수·옵션·구성·판매 정책이 근거와 일치한다. 생성 이미지, 다른 모델, 외형 치수를 호환 근거로 승격하지 않는다.
3. **정보 진전:** 앞 패널 및 FAQ 항목끼리 중복하지 않는다. 이미 나온 사실을 써도 새 선택 기준·예외를 제공해야 한다.
4. **정보 위계:** 답변이 주 영역이고 제품컷·제목·배지가 압도하지 않는다. 간결한 정렬·구분과 질문/답변의 위계가 실제 결과에 보인다.
5. **문자·모바일:** 정확 문자열, 누락·깨짐·잘림, 대비·행간을 확인한다. 원본과 모바일 폭(약 360~430px의 실제 표시 또는 비율 보존 축소 미리보기) 둘 다 열어 본다. 확대해야만 읽히면 카피/배치를 수정한다. 미리보기를 못 열면 모바일 항목은 미검증이다.
6. **규격·인계:** 최종 파일·해시·크기·FAQ ID·직접 열람·미해결 사실을 기존 자산 review에 연결한다. 구조 검증기는 시각 판단이나 전환율을 증명하지 않는다.

내용 실패는 질문·근거·답변부터, 시각 실패는 위계·문장 길이·배치부터 고친 뒤 해당 전체 패널을 호스트에서 다시 생성/편집한다. 같은 문제가 두 번 반복되면 축약·정보 재배치 등 대안을 제시하고 미해결 상태를 유지한다. 문구나 파일이 바뀌면 해당 검수도 갱신한다.

## 검토된 개선 사례

관찰된 대화의 요약이며 원문 로그나 실제 제품 성능 자료가 아니다. 사용자·로컬 경로·터널 주소·식별자는 제외했다.

- **관찰:** 가상 파우치 FAQ 첫 시안은 큰 제품 사진과 제목, 장식적인 서체, 크기·포켓·구성·관리법의 사양 질문으로 구성됐다.
- **사용자 정정:** 간결한 정보 중심 디자인과 구매를 최종 결정하는 사람을 위한 질문·답변을 요구했다.
- **관찰된 수정:** 작은 제품컷, 산세리프, 얇은 구분선, 구매 상황을 반영한 질문으로 개선됐다. 실제 매출이나 구매 전환 개선은 측정하지 않았다.
- **추출할 규칙:** 시각 개선과 답변의 충분성은 별개로 검수한다. 수정본도 내부 실측 없이 외형만 제시한 수납 답변은 호환 보장의 근거가 되지 않는다. 제품별 부족한 근거를 확보하거나 답할 수 있는 질문으로 좁힌다.
- **전이 금지:** 파우치의 질문·사양·초록색·파란 강조색을 모든 제품에 고정하지 않는다. 질문 선정 원리와 위계만 재사용한다.
