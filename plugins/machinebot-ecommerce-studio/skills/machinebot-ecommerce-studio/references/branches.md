# 제작 분기

제품 특성, 현재 보유 사진, 판매 채널, 구매 결정에 필요한 정보를 보고 분기를 고른다. 사용자가 탐색 중이면 아래 중 적합한 2~3개만 제안한다.

## 1. 메인·서브 썸네일 세트

적합한 경우: 검색 목록에서 제품 식별과 클릭을 먼저 확보해야 할 때.

기본 산출물:

- 메인 1장: 1:1, 중성 흰색 스튜디오, 제품 중심, 불필요한 글자·소품 없음
- 서브 5~7장: 다른 각도, 구성품, 크기·디테일, 사용 상황, 핵심 효용
- 총 6~8장

제품 사진이 있으면 참조 편집을 우선한다. 판매 채널의 최신 등록 규칙을 확인하지 않았다면 “업로드 규격 준수”를 단정하지 않는다.

## 2. 누끼컷

적합한 경우: 합성, 썸네일, 상세페이지에 쓸 깨끗한 마스터 제품 자산이 없을 때.

기본 산출물:

- 투명 배경 PNG 1~4장
- 정면과 사용 가능한 범위의 3/4 각도·측면
- 자연스러운 접지 그림자가 필요한 경우 별도 버전

실물의 보이지 않는 면을 추측하지 않는다. 단순 배경 제거로 충분하면 생성보다 정확한 마스킹을 우선한다.

## 3. 연출·실사용컷

적합한 경우: 고객이 제품이 놓일 공간, 사용하는 순간, 원하는 라이프스타일을 상상해야 할 때.

기본 산출물:

- 4~10장
- 제품 단독 연출, 손 또는 인물 사용, 환경 와이드, 재질 디테일을 균형 있게 구성
- 한 세트 안에서 팔레트, 광원, 소품 수준, 제품 크기를 통일

제품보다 소품이 강해지지 않게 한다. 인물이 등장하면 제품 사용 방식과 신체 접촉이 자연스러운지 확인한다.

## 4. 효용·기능 시각화컷

적합한 경우: 열·냉기·공기 흐름·수분·흡수·압력 분산·구조처럼 사진만으로 이해하기 어려운 장점이 있을 때.

기본 산출물:

- 3~6장
- 제품 원형을 보존한 시각 효과 버전
- 필요 시 단면·폭발도·전후 과정·재료 레이어

시각 효과는 이해를 돕는 은유다. 검증된 수치가 아니면 온도, 시간, 강도, 개선율 같은 측정값을 이미지에 넣지 않는다. 과학적 단면처럼 보이는 그림은 실제 구조 근거가 있을 때만 사용한다.

## 5. 상세페이지 이미지

적합한 경우: 구매 설득 흐름과 한국어 카피를 6~10장의 세로 이미지로 완성해야 할 때.

기본 산출물:

- 6·8·10장 중 제품 복잡도에 맞는 패널 수
- 패널당 기본 1080 × 2160px, 최소 세로 2000px
- 마지막 패널에 FAQ 포함
- 패널별 이미지 생성 원본과 채널 규격으로 정규화한 최종본을 구분해 보관

패널 설계는 [상세페이지 설계](detail-page-blueprint.md)를 따른다.

## 6. 전체 이미지 패키지

적합한 경우: 신규 상품 출시나 리뉴얼처럼 판매 페이지 전체 자산이 필요한 때.

`라이트` 기본:

- 마스터 누끼 1~2장
- 썸네일 6장
- 연출·실사용컷 4장
- 효용 시각화컷 3장
- 상세페이지 6장

`풀` 기본:

- 마스터 누끼 2~4장
- 썸네일 6~8장
- 연출·실사용컷 6~10장
- 효용 시각화컷 3~6장
- 상세페이지 8~10장

호출량이 크므로 라이트와 풀의 수량을 보여주고 한 번 선택받는다. 같은 마스터 제품 컷과 하나의 시각 시스템을 모든 자산에서 재사용한다.
