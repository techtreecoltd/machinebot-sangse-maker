# 제작 분기

제품 특성, 현재 보유 사진, 판매 채널, 구매 결정에 필요한 정보를 보고 분기를 고른다. 탐색 중이면 [시작 질의응답](intake-routing.md)으로 부족한 항목만 확인한 뒤 전체 패키지를 포함해 총 2~3개를 제안한다. 부적합한 후보로 수를 채우지 않는다. 명시 요청은 메뉴 없이 해당 분기로 직행한다.
단순 누끼를 제외한 신규 판매 제작은 [소구 설계와 장점 시각화](sales-visual-strategy.md)에 따라 제품 장점·고객 가치·근거·장면을 연결한다. 다음 분기는 납품 형태이며, 상세페이지 안에 연출·효용 시각화를 넣기 위해 다른 분기를 추가로 선택할 필요는 없다.

## 1. 메인·서브 썸네일 세트

적합한 경우: 검색 목록에서 제품 식별과 클릭을 먼저 확보해야 할 때.

기본 산출물:

- 메인 1장: 1:1, 중성 흰색 스튜디오, 제품 중심, 불필요한 글자·소품 없음
- 서브 5~7장: 다른 각도, 구성품, 크기·디테일, 사용 상황, 핵심 효용
- 총 6~8장

제품 사진이 있으면 참조 편집을 우선한다. 판매 채널의 최신 등록 규칙을 확인하지 않았다면 “업로드 규격 준수”를 단정하지 않는다.

## 2. 누끼컷

적합한 경우: 합성, 썸네일, 상세페이지에 쓸 깨끗한 마스터 제품 자산이 없을 때.

기본 산출물:

- 흰색 스튜디오 제품 마스터컷 1~4장
- 정면·3/4·측면·상부 등 자료로 확인 가능한 서로 다른 각도
- 중성 화이트밸런스, 큰 확산광, 자연스러운 접지 그림자, 깨끗한 여백

실행은 [독립 누끼 스킬](../../machinebot-product-cutout/SKILL.md)과 [제품 스튜디오 마스터컷](studio-product-shots.md)을 따른다. 실물의 보이지 않는 면을 추측하지 않고 제품 형상·색상·인쇄를 보존한 채 배경·조명·카메라만 바꾼다. 투명 배경 파일이 필요하면 별도 추가 요청으로 기록하며 기본 누끼 산출물 수량을 대신하지 않는다.

## 3. 연출·실사용컷

적합한 경우: 고객이 제품이 놓일 공간, 사용하는 순간, 원하는 라이프스타일을 상상해야 할 때.

기본 산출물:

- 4~10장
- 제품 단독 연출, 손 또는 인물 사용, 환경 와이드, 재질 디테일을 균형 있게 구성
- 한 세트 안에서 팔레트, 광원, 소품 수준, 제품 크기를 통일

제품보다 소품이 강해지지 않게 한다. 인물이 등장하면 제품 사용 방식과 신체 접촉이 자연스러운지 확인한다.

## 4. 효용·기능 시각화컷

적합한 경우: 열·냉기·공기 흐름·수분·흡수·압력 분산·구조처럼 사진만으로 이해하기 어려운 장점이 있을 때.

기본 산출물:

- 3~6장
- 제품 원형을 보존한 시각 효과 버전
- 필요 시 단면·폭발도·전후 과정·재료 레이어

시각 효과는 이해를 돕는 은유다. 검증된 수치가 아니면 온도, 시간, 강도, 개선율 같은 측정값을 이미지에 넣지 않는다. 과학적 단면처럼 보이는 그림은 실제 구조 근거가 있을 때만 사용한다.
수치가 없어도 효과 자체가 기능을 주장할 수 있으므로 해당 기능의 근거부터 확인한다. 장점을 보여주는 실제 사용 동작·필요 상황만으로 충분하면 화살표·단면을 억지로 추가하지 않는다.

## 5. 상세페이지 이미지

적합한 경우: 구매 설득 흐름과 한국어 카피를 6~10장의 세로 이미지로 완성해야 할 때.

기본 산출물:

- 6·8·10장 중 제품 복잡도에 맞는 패널 수
- 패널당 기본 1080 × 2160px, 최소 세로 2000px
- 마지막 패널에 FAQ 포함
- 패널별 이미지 생성 원본과 채널 규격으로 정규화한 최종본을 구분해 보관

패널 설계는 [상세페이지 설계](detail-page-blueprint.md)를 따른다.
소구별로 필요한 새 연출과 장점 시각화를 이 분기 안에서 제작한다. 같은 사진·포즈의 반복을 여러 패널의 주 이미지로 사용하지 않는다.

## 6. 전체 이미지 패키지

적합한 경우: 신규 상품 출시나 리뉴얼처럼 판매 페이지 전체 자산이 필요한 때.

`라이트` 기본:

- 마스터 누끼 1~2장
- 썸네일 6장
- 연출·실사용컷 4장
- 효용 시각화컷 3장
- 상세페이지 6장

`풀` 기본:

- 마스터 누끼 2~4장
- 썸네일 6~8장
- 연출·실사용컷 6~10장
- 효용 시각화컷 3~6장
- 상세페이지 8~10장

호출량이 크므로 라이트와 풀의 수량을 보여주고 한 번 선택받는다. 같은 제품 정체성 기준과 하나의 시각 시스템을 모든 자산에 적용하되, 소구와 역할에 맞춰 장면을 바꾼다. 분기 사이에서 완성 자산을 재사용하면 새 연출 수에 중복 산입하지 않고 납품 목록에 표시한다.
