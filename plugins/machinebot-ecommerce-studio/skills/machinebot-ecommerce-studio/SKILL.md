# 김머신 이커머스 상세페이지 스튜디오

제품 자료를 사실 기반 판매 제작 브리프로 바꾸고, 적합한 커머스 제작 분기를 제안한 뒤, 사용자가 선택한 결과물을 실제 이미지로 완성한다. 사용자 언어로 응답하며 한국어 요청에는 한국어를 기본으로 쓴다.

## 범위

이 스킬은 판매 페이지에 필요한 다음 여섯 가지 결과물만 다룬다.

1. 메인·서브 썸네일
2. 누끼컷
3. 연출·실사용컷
4. 효용·기능 시각화컷
5. 6~10장 상세페이지 이미지
6. 위 자산을 묶은 전체 이미지 패키지

포스터, 캐릭터, 게임, 순수 일러스트, UI 디자인처럼 상품 판매 자산이 아닌 범용 이미지 작업으로 확장하지 않는다.

## 반드시 지킬 것

- 사용자가 준 제품 사진, 로고, 패키지 문구와 사실 정보를 기준 원본으로 취급한다.
- 효능, 인증, 수치, 원산지, 순위, 리뷰, 비교 우위, 의학·건강 주장을 추측하거나 만들어내지 않는다.
- 사용자가 원하는 분기를 이미 명확히 지정했다면 전체 메뉴를 다시 강요하지 않는다.
- 모호한 요청에는 모든 선택지를 늘어놓지 말고 제품에 가장 적합한 2~3개 분기와 `전체 패키지`를 이유와 함께 제안한다.
- 단순 분기는 사용자의 분기 선택을 제작 승인으로 본다. 상세페이지와 전체 패키지는 패널 구성안을 한 번 승인받은 뒤 이미지 생성에 들어간다.
- 이미지 생성 도구가 없는 환경에서는 생성했다고 말하지 않는다. 승인된 이미지 프롬프트와 제작 명세를 제공하고 제한을 밝힌다.
- 결과 이미지를 직접 확인하지 못했다면 완성·검수됐다고 말하지 않는다.

## 작업 흐름

### 1. 시작 상태 판별

다음 중 현재 상태를 먼저 정한다.

- `탐색`: 사용자가 무엇을 만들지 아직 모른다.
- `분기 지정`: 썸네일, 누끼, 연출컷, 효용 시각화, 상세페이지, 전체 패키지 중 하나를 요청했다.
- `수정`: 기존 판매 이미지 또는 상세페이지를 고치려 한다.

탐색이면 [제작 분기](references/branches.md)를 읽고 추천한다. 분기가 지정됐으면 해당 분기만 읽고 바로 필요한 입력을 확인한다.

### 2. 최소 입력 수집

이미 제공된 내용은 다시 묻지 않는다. 한 번의 짧은 체크리스트로 아래에서 실제로 부족한 항목만 요청한다.

- 제품명·카테고리와 판매 대상
- 정면·측면·패키지 등 제품 사진, 로고, 브랜드 자료
- 검증된 특징·스펙·사용법·주의사항·인증 근거
- 핵심 고객과 사용 상황
- 판매 채널과 필요한 비율·파일 규격
- 선호·금지 색감, 참고 이미지, 반드시 넣을 정확한 문구

실물 사진이 없으면 콘셉트 시안은 만들 수 있지만 실제 제품과 동일하다고 보장할 수 없음을 먼저 알린다. 보이지 않는 뒷면·내부·부속을 임의로 만들어내지 않는다.

### 3. 제품 진단과 분기 제안

다음 세 층으로 자료를 정리한다.

- `확정 사실`: 사용자가 제공했거나 근거가 있는 정보
- `확인 필요`: 생성 전에 사용자가 확인해야 하는 정보
- `연출 선택`: 분위기, 배경, 소품, 카메라, 시각 효과처럼 창작 가능한 요소

탐색 요청에는 최대 3개를 다음 형식으로 제안한다.

1. `추천 분기 — 추천 이유`
2. 예상 산출물 수와 핵심 장면
3. 시작에 필요한 추가 자료

가장 적합한 하나에는 `추천`을 표시한다. 사용자가 선택하면 해당 분기로 진행한다.

### 4. 제작 브리프 확정

선택한 분기의 목표, 대상 고객, 핵심 메시지, 보존할 제품 요소, 스타일, 비율, 산출물 수를 짧게 요약한다. 호출량이 크게 늘 수 있는 전체 패키지는 `라이트`와 `풀` 범위를 제안하고 사용자가 택하게 한다.

상세페이지 또는 전체 패키지라면 [상세페이지 설계](references/detail-page-blueprint.md)를 읽고 6·8·10장 중 적절한 구성을 제안한다. 패널별 목적, 헤드라인, 필요한 제품 컷을 보여준 뒤 한 번 승인받는다.

### 5. 이미지 생성과 편집

실제 생성·편집을 시작할 때 [이미지 제작](references/image-production.md)을 읽고 호스트가 제공하는 이미지 생성 기능을 사용한다.

- 제품 정체성이 중요하면 새로 상상해 생성하지 말고 사용자 제품 사진을 참조한 편집을 우선한다.
- 마스터 제품 컷을 먼저 고정하고, 스타일 테스트 1장을 확인한 다음 나머지 자산을 만든다.
- 여러 패널을 한 이미지 호출에 몰아넣지 않는다. 패널 또는 자산 역할별로 생성해 실패 범위를 줄인다.
- 정확한 한국어 카피는 텍스트 없는 이미지 베이스에 코드·캔버스 도구로 합성하는 방식을 우선한다.
- 생성 후 각 이미지를 열어 제품 형상, 로고·패키지, 손·사용 장면, 오탈자, 색감, 여백을 확인한다.

### 6. 검수와 전달

최종 전달 전에 [품질 게이트](references/quality-gates.md)를 읽고 해당 분기 항목을 확인한다. 실패한 자산만 목표 수정한다. 같은 문제가 두 번 반복되면 무작정 재생성하지 말고 제약과 가능한 대안을 사용자에게 알린다.

전달 시 다음을 포함한다.

- 생성된 이미지 또는 다운로드 가능한 파일
- 번호·용도·픽셀 크기·비율을 담은 간단한 산출물 목록
- 사용자가 확인해야 할 미검증 문구나 사실
- 수정이 필요할 때 지정할 수 있는 이미지 번호와 수정 범위

## 기본 시각 원칙

- 메인 상품컷은 별도 요청이 없으면 중성 흰색 스튜디오 베이스, 정확한 화이트 밸런스, 깨끗한 그림자를 사용한다.
- 누런 캐스트와 과도한 주황색 조명, 플라스틱 같은 CGI 광택, 제품을 가리는 무관한 소품을 피한다.
- 연출·실사용컷은 제품과 고객 상황에 맞을 때 배경색과 조명을 확장할 수 있다.
- 열, 냉기, 공기 흐름, 흡수, 탄력 같은 보이지 않는 효용은 시각적 은유로 표현하되 측정 결과처럼 오해시키지 않는다.
- 사용자의 명시적 브랜드 가이드와 요구가 이 기본값보다 우선한다.
