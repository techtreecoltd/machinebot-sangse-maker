# 연출·실사용컷

진입 시 [공통 제작 계약](../machinebot-ecommerce-studio/references/production-contract.md)과 [제품 기록](../machinebot-ecommerce-studio/references/product-context.md)을 읽는다. 기록이 있으면 원본·옵션·해시·검수를 확인해 이어 쓰고, 없으면 제공된 사진으로 시작한다. 누끼가 없어도 원본으로 진행한다. 실패 누끼는 참조하지 않는다.

1. 명시된 목적·수량·금지 요소를 유지한다. 기본 4~10장이나 사용자가 한 장 등 수량을 지정하면 그 범위로 제작한다. 사용 상황·제품 크기·접촉 방식 중 장면을 좌우하는 누락만 확인한다.
2. [소구 설계](../machinebot-ecommerce-studio/references/sales-visual-strategy.md)를 읽고 소구·근거·새 구매 정보를 연결한다. 제품 단독 연출, 손/인물 사용, 환경 와이드, 유효한 디테일 중 해당 제품에 맞는 장면을 고른다. 인물이 필요 없는 제품에 사람을 억지로 넣지 않는다.
3. 장면 표에 ID·행동·배경·구도·보여줄 가치·근거·이전 컷과의 차이를 적는다. 같은 사진 크롭·포즈·배경색 변경으로 수를 채우지 않는다. 팔레트·광원·소품 밀도는 세트에서 일관되게 유지한다.
4. 원본 제품을 정체성 기준으로, 검수 자산을 보조 참조로 사용한다. [제작 절차](../machinebot-ecommerce-studio/references/image-production.md)에 따라 자산별 호스트 호출로 생성한다. 형상·옵션·로고를 잠그고 배경·행동·구도만 장면에 맞게 바꾼다. 글자가 필요하면 같은 호출에 포함한다.
5. [품질 게이트](../machinebot-ecommerce-studio/references/quality-gates.md)로 실제 파일을 연다. 제품이 동일한지, 손·접촉·크기 관계가 가능한지, 소품이 제품을 가리지 않는지, 근거 없는 기능을 시각적으로 주장하는지 확인한다. 전체 세트에서 각 컷의 역할을 구별한다.
6. 실패한 컷만 수정하고 실제 검수 결과를 제품 기록에 반영한다. 결과와 번호·용도·크기·미해결 항목을 전달한다. 단독 연출은 여기서 종료하며 상세페이지를 자동 시작하지 않는다. 승인된 패키지/후속 요청만 통과 자산과 원본 기록을 이어 받는다.

예: 기준 제품 사진과 “책상에서 쓰는 4장” → 책상 배치 / 물건을 넣는 손 / 꺼내는 손 / 내부 구분이 보이는 상부 구도. 실제 구조·크기가 확인된 물건만 넣으며 새 효능이나 특정 기종 호환성을 발명하지 않는다.
