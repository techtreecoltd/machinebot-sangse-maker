# 메인·서브 썸네일

[공통 계약](../machinebot-ecommerce-studio/references/production-contract.md)과 [제품 기록](../machinebot-ecommerce-studio/references/product-context.md)을 읽고 원본·옵션·검수 자산을 이어 받는다. 원본이 충분하면 누끼를 먼저 만들지 않는다. 직접 요청에는 추천 메뉴를 반복하지 않는다.

1. 기본 메인 1장 + 서브 5~7장, 총 6~8장이다. 명시한 수량·규격은 우선한다. 기본 메인은 1:1·중성 흰 배경·제품 중심·불필요한 글자와 소품 없음이다. 채널의 최신 규칙을 실제 확인하지 않았다면 업로드 규격 준수를 단정하지 않는다.
2. [소구 설계](../machinebot-ecommerce-studio/references/sales-visual-strategy.md)로 서브마다 다른 구매 질문을 배정한다. 확인된 각도·구성·디테일·사용·효용 중 근거 있는 항목만 고른다. 치수 사진/근거 없이 자·숫자·호환 기종을 그리지 않는다. 단순 부분 수정에 전체 소구 설계를 반복하지 않는다.
3. [이미지 제작](../machinebot-ecommerce-studio/references/image-production.md)에 따라 각 자산을 호스트에서 생성/편집한다. 글자가 필요한 서브는 제품·장면·정확 문구를 같은 호출로 렌더링한다. 흰 메인의 제품은 원본 색·비율·로고가 기준이다.
4. [품질 게이트](../machinebot-ecommerce-studio/references/quality-gates.md)로 각 실제 결과와 세트를 확인한다. 작은 썸네일에서도 제품이 식별되고 잘림·로고 변형·과장 효과·읽히지 않는 문구가 없어야 한다. 배경/문구만 바꾼 복제품으로 서브 장수를 채우지 않는다.
5. 실패 자산만 수정하고 제품 기록과 목록에 반영한다. 요청한 썸네일 세트를 전달한 뒤 종료한다. 패키지 승인/새 후속 요청이 있을 때만 다음 제작을 이어 간다.

예: “메인 한 장만” → 원본 확인 → 흰 배경 정사각형 메인 생성·검수 → 한 장 전달. 서브 5장을 자동으로 추가하지 않는다.
