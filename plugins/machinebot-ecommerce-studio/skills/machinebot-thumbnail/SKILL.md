# 메인·서브 썸네일

[시작 안내](../machinebot-ecommerce-studio/references/start-here.md), [공통 계약](../machinebot-ecommerce-studio/references/production-contract.md), [제품 기록](../machinebot-ecommerce-studio/references/product-context.md)을 읽고 원본·옵션·검수 자산을 이어 받는다. 충분한 원본이 있으면 누끼를 선행 생성하지 않는다. 명시 요청에는 전체 메뉴를 반복하지 않는다.

1. 범위·수량·채널·위치와 표현 지시를 확인한다. “메인 썸네일”은 메인 1장이다. “썸네일 세트”의 수량 미지정일 때만 메인 1장+서브 5~7장을 사용한다. 비율 미지정은 1:1이며 메인을 흰 배경·무문자로 자동 결정하지 않는다.
2. 제공된 모든 사진·문구를 확인하고 역할·옵션·주장 근거를 구분한다. [표현 선택](references/thumbnail-design.md)을 메인 한 장에도 적용해 구매 질문, 선택 표현과 이유, 자료 사용/제외, 구도, 카피, 채널 확인 상태를 짧게 기록한다. 모델·사용컷, 장점 시각화, 스튜디오컷, 정보성·후킹 문구와 그 조합을 자료와 목적에 맞게 판단한다.
3. [소구 설계](../machinebot-ecommerce-studio/references/sales-visual-strategy.md)의 근거 기준으로 메인·서브의 메시지를 정한다. 필요한 경우 [CG 판단](../machinebot-ecommerce-studio/references/cg-visualization-catalog.md)을 읽는다. 서브마다 다른 구매 질문을 배정하며 치수·효능·호환성을 발명하지 않는다. 최신 채널 규칙을 확인하지 않았다면 준수를 단정하지 않는다.
4. 방향을 한두 문장으로 알리고 [이미지 제작](../machinebot-ecommerce-studio/references/image-production.md)에 따라 생성한다. 단독 요청은 제작 승인이다. 필요한 모델·제품·장면·효과·정확 문구를 자산별 한 번의 호스트 호출에서 함께 렌더링한다. 문구 오버레이 디자인은 메인에도 사용할 수 있으며 별도 글자 레이어·코드 합성은 금지다.
5. [품질 게이트](../machinebot-ecommerce-studio/references/quality-gates.md)와 표현 선택의 결과 검수로 실제 이미지를 연다. 작은 썸네일에서 제품과 의도한 구매 메시지가 식별되고, 잘림·제품 변형·과장 효과·깨진 카피가 없는지 확인한다. 규격만으로 pass를 주지 않는다. 배경·문구만 바꾼 복제품으로 서브 장수를 채우지 않는다.
6. 실패 자산만 수정하고 제품 기록과 목록에 반영한다. 완성 이미지를 대화에 직접 표시하고 저장 위치·크기를 함께 전달한다. 호스트에서 표시할 수 없으면 그 제한을 밝힌다. 요청 범위에서 종료하고 후속 승인 없이 추가 자산을 생성하지 않는다.

예: “이 사진으로 메인 한 장” → 자료 전체와 사용 맥락 확인 → 적합한 표현·소구 선택 → 한 장 생성·직접 검수·표시. “흰 배경, 글자 없이”가 명시됐으면 해당 스튜디오컷으로 진행한다.
