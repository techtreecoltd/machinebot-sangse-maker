제품 사진과 사실 정보를 분석해 무엇을 만들지 먼저 제안하고, 선택한 분기를 호스트의 이미지 생성 기능으로 제작·검수하는 ChatGPT Work · Codex 플러그인입니다.

**버전 1.19.1** — 상세페이지 FAQ는 구매 직전 장벽을 질문·답변·근거로 정리하고, 작은 제품 식별 컷과 정보 중심 산세리프 레이아웃으로 제작·검수합니다.  시작 질의응답으로 필요한 제작 타입을 추천하고, 선택한 범위와 제품 자료를 기존 제작 절차에 연결합니다. 누끼를 흰색 스튜디오 제품 마스터컷으로 정의하고, 확인 가능한 여러 각도·전문 조명·접지 그림자를 직접 생성·검수합니다. 사진으로 보이지 않는 제품 가치는 CG 판단 카탈로그로 연출·효용·상세 흐름에 연결합니다.


## 처음 사용하는 방법

제품 사진과 원하는 결과를 주면 자료 전체를 확인하고 필요한 제작만 진행합니다. 납품 종류와 시각 표현은 따로 판단합니다. **메인 썸네일 한 장도 모델·사용컷, 장점 시각화, 스튜디오컷, 큰 문구의 정보성·후킹 컷을 고르거나 조합**할 수 있습니다. 메인이라는 이유만으로 흰 배경·무문자로 정하지 않습니다.

| 요청 예시 | 진행 방식 |
|---|---|
| “이걸로 메인 썸네일 만들어줘” | 자료의 역할·구매 이유·채널 조건을 보고 표현을 선택해 한 장 제작 |
| “모델 사용 사진에 이 문구를 크게 넣어줘” | 지정 사진과 카피를 한 이미지 호출에서 함께 완성 |
| “흰 배경, 글자 없이 제품컷 한 장” | 명시한 스튜디오컷으로 바로 제작 |
| “상세페이지 만들어줘” | 해당 기획자의 구성안을 먼저 확인하고 승인 후 제작 |

사진이 여러 장이면 모두 확인한 뒤 실제 입력을 고르고, 다른 색상·옵션은 섞지 않습니다. 단일 이미지 요청에는 같은 승인을 다시 묻지 않습니다. 결과는 가능한 호스트에서 대화에 직접 보여주고 저장 파일도 제공합니다. 채널 등록 준수는 실제 확인한 요구사항 범위에서만 안내합니다.


## 할 수 있는 일

1. 메인 1장과 서브 5~7장으로 구성한 썸네일 세트
2. 흰색 스튜디오 제품 마스터컷 1~4장
3. 제품 단독 연출과 실제 사용 상황을 포함한 연출·실사용컷 4~10장
4. 열·냉기·흡수·구조 같은 보이지 않는 장점을 설명하는 효용 시각화컷 3~6장
5. 패널당 세로 2000px 이상인 6·8·10장 한국형 상세페이지
6. 위 자산을 하나의 시각 시스템으로 묶은 라이트·풀 전체 패키지

무엇이 필요한지 아직 정하지 않았다면 목적·자료·이번 범위에서 부족한 것만 기본 1~3개 질문합니다. 자료가 충분하면 질문을 생략하고, 전체 패키지를 포함해 총 2~3개 타입을 이유·산출물·추가 자료와 함께 추천합니다. 이미 결과물을 지정했다면 메뉴 없이 해당 분기로 바로 진행합니다.

예: “누끼 한 장만”은 제품 원본을 기준으로 흰색 스튜디오 제품컷 한 장을 만들고, 형상·색상·조명·그림자·배경을 직접 확인한 뒤 그 한 장으로 끝냅니다. 요청하지 않은 연출·상세페이지를 자동 생성하지 않습니다. 투명 PNG가 필요하면 별도 추가 요청으로 기록합니다. 이미 제공한 정보와 선택한 범위는 다음 제작에 이어 씁니다.

## 사용 예시

ChatGPT Work:

```text
@machinebot-ecommerce-studio 이 제품 사진을 보고
판매에 필요한 커머스 이미지 분기를 추천해 줘.
```

Codex:

```text
$machinebot-ecommerce-studio 이 제품의 8장 상세페이지를 만들어 줘.
제품 모양과 패키지 문구는 참조 사진 그대로 유지해 줘.
```

상세페이지와 전체 패키지는 패널 또는 자산 구성안을 먼저 보여주고 한 번 승인받은 뒤 이미지 생성에 들어갑니다.

## 소구에서 이미지까지

1. 고객의 사용 상황·욕구와 구매 장벽을 정합니다.
2. 제품 특징·장점을 기능적·감성적 가치로 풀고 근거를 연결해 주 소구를 선택합니다.
3. 소구마다 필요 상황, 사용 행동, 구조·표면, 확인된 기능 또는 근거 있는 CG 시각화 중 적절한 방식을 설계합니다.
4. 각 패널이 추가하는 구매 정보를 정하고 제품·장면·카피를 함께 생성합니다.
5. 실제 이미지의 소구 전달과 세트 전체의 장면 반복까지 검수합니다.

예: 확인된 분리 포켓을 설명할 때, 제품 사진을 반복하는 대신 소지품을 꺼내는 사용 장면과 열린 내부 구조로 구분 수납을 보여줍니다. 상세페이지 안의 연출·장점 시각화는 이 분기 안에서 제작합니다.

소재·성능 등 중요한 정보가 없으면 근거를 확보하거나 확인 가능한 소구로 구성합니다. 미확인 정보를 소비자용 페이지에 반복하지 않으며, 판매 필수 정보가 빠진 결과는 시안으로 구분합니다. 단순 누끼·배경 제거·오탈자 수정에 전체 기획을 새로 요구하지 않습니다.

## 준비하면 좋은 자료

- 제품명, 카테고리, 핵심 고객과 판매 채널
- 정면·측면·패키지 사진과 로고·브랜드 자료
- 검증된 특징, 스펙, 사용법, 주의사항과 인증 근거
- 선호·금지 색감, 참고 이미지, 반드시 넣을 정확한 문구
- 필요한 비율, 픽셀 크기와 파일 형식

모든 자료가 없어도 시작할 수 있습니다. 이미 제공된 내용은 다시 묻지 않고, 선택한 분기를 만드는 데 실제로 부족한 항목만 요청합니다.

## 제작 원칙

- 제품 사진과 검증된 사실을 기준 원본으로 사용합니다.
- 효능, 인증, 수치, 리뷰, 순위, 비교 우위를 임의로 만들지 않습니다.
- 제품 정체성이 중요한 경우 신규 생성보다 참조 이미지 편집을 우선합니다.
- 제품 정체성을 유지하면서 소구에 필요한 새 배경·행동·구도를 만듭니다. 같은 사진의 크롭·색감·문구 변경을 새 연출로 세지 않습니다.
- 검증되지 않은 기능은 시각 효과로도 주장하지 않습니다. 생성한 전후 이미지나 개념 표현을 실제 시험 증거처럼 쓰지 않습니다.
- 스튜디오 표현을 선택한 상품컷은 중성 흰색 배경과 접지 그림자를 사용합니다. 썸네일은 구매 질문에 맞는 모델·장점·정보성 카피 등을 별도로 선택합니다.
- 중국어·일본어 등 외국어 상세페이지는 원문의 제품·기능 구조만 추출하고, 이미지 생성 단계에서 원문 제거와 한국어 카피 렌더링을 함께 처리합니다.
- 모든 언어에서 제품·배경·효과·확정 카피를 패널별 한 번의 이미지 생성 또는 편집 호출로 완성합니다.
- 텍스트 없는 베이스, 투명 타이포그래피 PNG, 텍스트 패치, HTML·CSS·SVG·캔버스·시스템 폰트 합성을 사용하지 않습니다.
- 생성한 결과를 직접 확인하지 못하면 검수 완료라고 말하지 않습니다.

## 범위 밖

이 플러그인은 상품 판매 자산 전용입니다. 포스터, 캐릭터, 게임, UI, 순수 일러스트와 상품 판매에 무관한 범용 이미지 편집은 다루지 않습니다.

실제 이미지 생성에는 ChatGPT Work 또는 Codex 호스트의 이미지 생성·편집 기능이 필요합니다. 호스트에 해당 기능이 없으면 이미지 프롬프트와 제작 명세까지만 제공하며, 생성했다고 주장하지 않습니다.
소구·시각화 검수는 에이전트가 수행하는 절차이며 자동 평가나 매출 상승을 보장하지 않습니다.

독립 누끼: `$machinebot-product-cutout 이 제품 사진으로 흰색 스튜디오 제품컷 한 장을 만들어 줘.` 다른 제작도 원본과 검수 자산을 product-context.json으로 이어 받을 수 있습니다.

연출·실사용컷을 machinebot-lifestyle로 분리하고 원본·검수 자산을 재사용한다. 단독 연출은 상세페이지로 자동 확장하지 않는다.

상세페이지와 외국어 현지화를 machinebot-detail-page로 분리했다. 독립 자산 세트의 의무 생성 없이 구성 승인·6/8/10장·마지막 구매 결정형 FAQ·패널 동시 렌더링을 유지한다. Q&A 한 장이나 마지막 FAQ 수정은 전체 상세로 확장하지 않는다.

메인·서브 썸네일을 machinebot-thumbnail로 분리했다. 기본 6~8장과 명시 수량·규격, 채널 규정 확인 범위, 독립 납품을 유지한다.

효용·기능 시각화를 machinebot-benefit-visual로 분리했다. 근거 있는 구조·사용 장면만 허용하고 미검증 성능 효과·숫자·비교를 차단한다.
